# 一、前言  
  
    目前很多小程序，网站都会实名认证并且大多数会使用人脸识别验证，这里实践测试，挖掘到多个人脸识别漏洞绕过的案例。一下简单讲解三个漏洞类型案例。  
  
# 二、正文  
  
    这里是某个AI面试功能点，你填写身份证姓名信息进行实名认证后，会发送一个面试链接信息。  
  
![](https://mmbiz.qpic.cn/mmbiz_png/ianpxKPnLHoKjicST5UeGmjTK8QmicRLJLrWeGmucesE253kVsya7WYSTRAvL4V6TNq5axktFE9OdcUHic5zUmFEcgDgob1SJQt3Wg10nub2wbU/640?wx_fmt=png&from=appmsg "")  
  
    这里点击会跳转至小程序，输入手机号即可，这里其实已经存在一个漏洞点了，那就是手机号可以随意绑定，没有对手机号做校验  
  
      
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoI4ZpzRhAnZiawLM94HEAm9JxKnDUIddcIgotw4GT8b83ZYJdIcR3bl5AlxtuxwtibyMu3k8u4lYyx6p8zzHXkYzdiaic9IN7hFYsY/640?wx_fmt=png&from=appmsg "")  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoKOgf2ZuSGS0cfiaPnDWlibDV3fRVRQejtCmBmH05ztz3tBX8JibWw5SoiaMl8jmeX6vIBZAZ0qxI9VMK5dM7oucyJXTd9Xzg8JW74/640?wx_fmt=png&from=appmsg "")  
  
最后来到这一步，拍摄人脸照片上传  
  
![](https://mmbiz.qpic.cn/mmbiz_png/ianpxKPnLHoKFtOA2TxsWYJ0bSVsJ9NCiaLklCZoCfLJkm2x8bLvxoby9vl9dK8Dh3FnPicVsO9Y4jUQ9AvxqVW7ibwU4iawCaCI07VPqWEa2PRY/640?wx_fmt=png&from=appmsg "")  
  
因为这个小程序对手机清晰度有要求，所以使用AI进行处理一下照片。  
  
![](https://mmbiz.qpic.cn/mmbiz_png/ianpxKPnLHoIVjQkj95VD3GVqv3aleJts9h2Z2BqFtjsibSQWycFygPeJCdicKvrqOnu8b2JOnswaT3ceAtsickWnhAuiaLFluXG0kzOaEazk90Y/640?wx_fmt=png&from=appmsg "")  
  
直接上传  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoKCfnRZHicJM3RLnMtTeI22zib70YmiaRaKpaP7TUv8aHkEp6IUstOJIkx2zfMvomjzpCCEp8QLxEondRdDjgyJBSWk9WMsoeYaIE/640?wx_fmt=png&from=appmsg "")  
  
    直接绕过识别，进入面试阶段。整个流程相当于使用他人身份证信息填写简历信息再绕过人脸识别使用他人身份信息进行面试处理。  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoIIzF3O3nCQVEcwPhgibFmTSoSUMXNicdxfdGJA0J0QHgpvwv28oefEv8uK8lZyLcvh8qc4TTxAqzlc8rXKrXfZv49kgKse1uwZg/640?wx_fmt=png&from=appmsg "")  
  
同样填写身份证信息等，然后需要微信支付宝扫码进行人脸识别  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoKa4G2EcDBR4cdW7y3Eez7ADib4DHPswjeE3g8iciaZCCm1sbFKxVCPT16F6sOzbMvI0xalVsRFu0NO2lib3Blv3E1ib2GJ0UApcRRw/640?wx_fmt=png&from=appmsg "")  
  
使用另一个手机进行人脸录屏，这里录屏需要录制摇头画面即可，该系统不检测张嘴，眨眼  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoLIRpheDznicGPGZIzgZJNNsjGpWoaWicd5S7oSmtEY8Hym0ubgFItljNIMCeMlLicc1jZRkCPblWAnWrCiaUaiarGyphIiaGxClYNw0/640?wx_fmt=png&from=appmsg "")  
  
微信扫描二维码，点击确认  
  
进行人脸识别，把录屏的人脸视频对准摄像头，当识别成功会显示如下  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoJFiaazkXLDD4iaJDxqptw7npvyiblxxV7WQcfwRdxacQk1RkFuhXLp8ELJzYlx2zMs8TB2mw2rh8oYIibdmNR9TJARPTiag3DFy5zY/640?wx_fmt=png&from=appmsg "")  
  
识别完成回到网站界面，显示人脸识别验证通过，实名认证成功，因此我们成功通过手机录屏绕过人脸识别  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoJqOicpmoTQkXR3IuyhfLe9vYqcElh3gLicPwVXY4rESS2rD96dxqrbTibHYtRbUibnWjWHc7Et8rJjqnsmYzyHbiadWeicrmICskIJ8/640?wx_fmt=png&from=appmsg "")  
  
  
这个人脸识别功能我认为存在两个功能点，其一：可直接绕过人脸识别这一步直接提交信息，第二就是可以直接伪造人脸识别数据直接以接口的形式提交。  
  
某个个人信息采集平台，这个需要使用手机抓包，因为人脸识别调用摄像头，识别到使用电脑会直接弹窗不允许点击  
  
首先会先填写身份证信息等  
  
  
![](https://mmbiz.qpic.cn/mmbiz_png/ianpxKPnLHoLvTgYnCDQ8lNiavRdKdbAbnXqaTuapwz3PnH9LhphnebiaeenB2DAdZicQmrSnUamHx2G8bJjicXp9lSg1AMic2T7Mt3Lg5PBUMTf8/640?wx_fmt=png&from=appmsg "")  
  
![](https://mmbiz.qpic.cn/mmbiz_png/ianpxKPnLHoLDlNXVHp2aAZTb8CYicIbrWSuK8icbhhAlNFKSzX8Q0t2FWPWhpeAr5NsRhahsEBDXt313FhIAhX7hmLDVGgLa3Nl0xOUtBBKRo/640?wx_fmt=png&from=appmsg "")  
  
我们这里也是正常填写，然后验证码随便输入，提交抓包看看数据包信息  
  
这里字段太多，所以都打码了，简单总结就是，这个最终提交个人信息的请求包，会把用户人脸识别过程中输入的身份证，人脸识别图像保存为一个链接地址，然后把这个地址给这个数据采集请求包。  
  
因此这里存在一个问题，该网站并没有限制链接地址来源信息，也并没有验证用户是否进行人脸识别认证的过程  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoJXYaGqbgTCMhTb0tDspiaDdDvvYaxwu93ZcvQGXtoK5O4nCSnczX18BibT73BANGWLricGCaZpibv6wjV8S3aBCdrSq7Hg0qrIkys/640?wx_fmt=png&from=appmsg "")  
  
这里直接把身份证，人脸链接换成互联网上别人的或者随便找的图片链接地址给请求包，通过测试成功提交，相当于直接绕过人脸识别接口，直接提交最终请求包即可。  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ianpxKPnLHoI6HkwgWFcN7vnicgiaOQzmkMRz2MYstHGYQevsiceBgX8eta85IvdypTic5zM8LYbJTCkIknfvudp1E8t3J9j2icBIP4BszjOUvGDo/640?wx_fmt=png&from=appmsg "")
