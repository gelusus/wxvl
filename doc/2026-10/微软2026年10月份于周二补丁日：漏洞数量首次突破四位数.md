#  微软2026年10月份于周二补丁日：漏洞数量首次突破四位数  
原创 铸盾安全
                        铸盾安全  河南等级保护测评   2026-10-18 16:00  
  
# 2026年10月，微软再次刷新漏洞发布纪录，首次出现四位数的CVE数量，同时也是首次出现六位数编号的CVE。经统计，微软本月发布了1415个新CVE，超过以往任何一年。受影响产品涵盖Windows及其组件、Office及其组件、开发人员工具和.NET、SharePoint、Linux内核、Skype for Business和Microsoft Lync、SQL Server和Dynamics、Azure及其云服务，以及Exchange Server。  
  
尽管漏洞数量庞大，但本月**只有一个漏洞被列为正在遭受攻击**  
：CVE-2026-96951，一个Windows Shell安全功能绕过漏洞，CVSS评分为8.8，严重程度为“重要”。该漏洞利用Shell绕过Mark of the Web（MotW）保护，与2024年攻击者使用多种方法绕过MotW的情况类似。此外，还有两个漏洞被列为公开已知但未遭受攻击：CVE-2026-108398（.NET Framework安全功能绕过漏洞，CVSS 8.8，重要）和CVE-2026-92707（MessagePack-CSharp拒绝服务漏洞，CVSS 5.3，中等）。  
  
回顾2023年零日漏洞高峰期，1月至10月间微软共发现17个零日漏洞，而今年同期只有15个。2023年微软的CVE总数仅为914个。人工智能无疑加速了漏洞发现和修复，但零日漏洞利用率尚未出现同样增长。  
## 严重程度描述修正说明  
  
原稿中大量漏洞被标注为“批判的”（Critical），但根据微软官方严重程度评级，本月绝大多数漏洞实际为**“重要”（Important）**  
，少数为“**严重**  
”（Critical）和“中等”（Moderate）。以下按严重程度重新归类：  
  
**严重（Critical）漏洞**  
：主要集中在可导致远程代码执行且无需身份验证或用户交互的场景，包括Azure应用服务RCE（CVE-2026-77900，CVSS 9.8）、Azure SRE代理权限提升（CVE-2026-69435，CVSS 9.6）、Microsoft Bookings权限提升（CVE-2026-94510，CVSS 9.9）、微软数据宇宙RCE（CVE-2026-88131，CVSS 9.8）、微软合作伙伴中心权限提升（CVE-2026-96207，CVSS 10.0）、多个Outlook RCE（CVSS 9.8）、多个Excel RCE（CVSS 8.8）、多个PowerPoint RCE、Windows DHCP服务器RCE（CVE-2026-96934，CVSS 9.8）、Windows消息队列管理器RCE（CVE-2026-100202，CVSS 9.8）、Windows文本整形RCE（CVE-2026-97814，CVSS 9.8）、网络策略服务器RCE（CVE-2026-100222和85806，CVSS 9.8）、PostScript打印机驱动程序RCE（CVE-2026-70147和70153，CVSS 9.8）、QUIC RCE（CVE-2026-100219和105016，CVSS 9.8）、Windows错误报告RCE（CVE-2026-83519、83693、83748、97815，CVSS 9.8）、Windows搜索组件权限提升（CVE-2026-105010，CVSS 9.8）、BitLocker RCE（CVE-2026-96909，CVSS 9.8）、OLE RCE（CVE-2026-96924，CVSS 9.8）、分区管理驱动程序RCE（CVE-2026-97805，CVSS 9.8）、卷管理器扩展驱动程序RCE（CVE-2026-85928，CVSS 9.8）、故障转移群集RCE（CVE-2026-88102，CVSS 9.8）等。  
  
**重要（Important）漏洞**  
：占本月绝大多数，包括大量权限提升、信息泄露、拒绝服务、安全功能绕过和部分远程代码执行漏洞。例如Windows内核权限提升（多数CVSS 7.8）、Win32k权限提升、NTFS权限提升、Windows Installer权限提升、SharePoint权限提升和RCE、SQL Server RCE和权限提升、远程桌面客户端RCE、Hyper-V RCE和权限提升等。  
  
**中危（Moderate）漏洞**  
：如MessagePack-CSharp拒绝服务漏洞（CVE-2026-92707，CVSS 5.3）。  
## 重点漏洞分析  
  
**CVE-2026-96951 — Windows Shell安全功能绕过漏洞**  
：本月唯一被列为正在遭受攻击的漏洞，CVSS 8.8，重要。攻击者利用Shell绕过MotW保护。请尽快测试并部署。  
  
**CVE-2026-102866 — Microsoft Office SharePoint权限提升漏洞**  
：CVSS 8.1，**严重**  
。本月唯一被评为批判的SharePoint CVE，也是唯一未经身份验证即可利用的漏洞。属于加密签名验证不当，攻击者获得有效验证令牌后可修改并以该用户身份认证。  
  
**CVE-2026-65674 — Microsoft SQL Server远程代码执行漏洞**  
：CVSS 8.8，重要。利用不受信任数据的反序列化，经过身份验证的攻击者可连接SQL Server并发送精心构造的请求执行代码，无需用户交互。务必检查直接连接Internet的SQL Server。  
  
**CVE-2026-70571 — Microsoft Exchange Server远程代码执行漏洞**  
：CVSS 8.1，**严重**  
。微软表示利用需要攻击者对目标环境有深入了解，且不能保证成功，实际利用可能性极低。  
## 可蠕虫利用漏洞  
  
本月共有**59个CVE**  
符合可蠕虫利用定义，即未经身份验证的攻击者可通过网络发送特制数据包利用，且无需身份验证或用户交互。主要包括：DHCP服务器（6个）、网络策略服务器（4个）、Windows错误报告（4个）、远程桌面网关（3个）、文本整形（3个），以及QUIC、Schannel、DNS服务器、媒体基础、Microsoft XML、RRAS、PostScript打印机驱动程序各2个，另有25个组件各1个。如此多可蠕虫利用漏洞应引起重视，但不必恐慌，请及时测试并部署修复程序。  
## 其他重点领域  
  
**本地权限提升**  
：677个权限提升漏洞中，606个（90%）可导致SYSTEM、管理员或root权限获取。另有10个可从低完整性提升至中等完整性，6个可逃逸低完整性或应用程序容器沙箱。  
  
**Office相关漏洞**  
：共139个CVE，包括100个RCE、29个信息泄露、9个权限提升和1个安全功能绕过。Outlook有5个严重RCE（CVSS 9.8），仅阅读窗格查看邮件即可触发。Excel有69个漏洞，其中51个RCE。Word新增22个漏洞。Access有12个RCE，Visio有3个严重RCE，PowerPoint有3个严重RCE。  
  
**DNS和DNS服务器**  
：共58个CVE，均为重要，包括CVE-2026-96113（CVSS 9.8 RCE）。大多数（31个）导致信息泄露。  
  
**Windows内核和Win32k**  
：共94个CVE，71个权限提升、20个信息泄露、2个DoS、1个安全功能绕过。  
  
**Windows DHCP**  
：共18个CVE，DHCP服务器16个、客户端2个，包括多个可蠕虫利用漏洞。  
  
**SharePoint Server**  
：除严重漏洞外，另有34个CVE，包括13个权限提升、7个欺骗、7个RCE、6个信息泄露、1个篡改。  
  
**SQL Server和客户端**  
：除RCE外另有23个CVE，模式为经过身份验证的内存损坏。CVE-2026-103572存在于SQL Server Management Studio中，通过Copilot注入提示符执行代码。  
  
**Windows Installer**  
：38个CVE，35个权限提升（34个导致SYSTEM）、3个信息泄露。释放后使用（20个）最多。  
  
**Windows NTFS**  
：26个CVE，16个权限提升、6个信息泄露、4个RCE。5个权限提升为沙箱逃逸漏洞。  
  
**远程桌面和远程访问**  
：远程桌面及组件30个CVE，远程桌面客户端19个CVE（18个RCE，多为释放后使用），RRAS新增13个CVE。  
  
**Hyper-V**  
：18个CVE，包括CVE-2026-102214和105733（CVSS 8.8 RCE，虚拟机到主机场景）。  
  
**其他值得注意**  
：Windows消息队列服务CVE-2026-100202（CVSS 9.8释放后使用，默认未启用）、VBS Enclave五个严重漏洞、图像组件/libarchive/媒体播放器/iSCSI多个9.8 RCE、Windows PDF（CVE-2026-108457）、PostScript打印机驱动程序（CVE-2026-108467）、HEVC视频扩展（CVE-2026-108400）严重RCE，以及AD FS欺骗（CVE-2026-108131）、Exchange XSS（CVE-2026-70279）、VS Code RCE（CVE-2026-102238）。  
## 微软“风险群组”新机制  
  
微软本月引入“风险群组”，称其为探索性方法，帮助客户组织分析，并非官方漏洞分类，不改变更新指南，也不取代单个CVE评估。一个组件可能在一份公告中包含多个CVE，微软现以群组形式重新引入这一概念。任何简化每月更新流程的举措都值得欢迎。  
## 展望  
  
下一次补丁星期二将于11月10日举行。单次发布数百个CVE曾属例外，如今已成常态。人工智能加速了双方漏洞搜寻，但漏洞发现速度远超漏洞利用速度。团队不应仅根据CVE数量判断漏洞利用优先级，而应修复已被证实、优先级高且已公开的漏洞，将其他视为新常态。
