近日，国际软件工程领域顶级学术会议ASE 2026在德国慕尼黑举办，360携AI安全研究成果《Evidence-Grounded Logic Vulnerability Detection for Smart Contracts via Runtime Context Reasoning》（基于运行时上下文推理的智能合约逻辑漏洞证据化检测，以下简称“RcAudit”）亮相大会。该研究由360与清华大学联合开展，相关技术作为360 AI安全攻防系统“图龙锋”的能力组成部分，创新性地将大语言模型语义推理与真实运行时证据相结合，在复杂业务逻辑漏洞检测方面取得新突破。在真实项目审计中，该技术发现22个此前未披露的安全漏洞，展现出AI自动化漏洞挖掘的实战能力。

ASE是软件工程领域具有重要国际影响力的学术会议，聚焦软件测试、程序分析、自动化软件工程等前沿研究方向。继2025年相关研究成果获得ASE杰出论文奖后，360再次凭借AI安全技术创新获得国际学术关注和认可，体现了其在智能化漏洞挖掘领域持续深入的技术积累。  
  
  
随着区块链、去中心化金融（DeFi）等技术快速发展，智能合约已成为数字资产交易和管理的重要基础设施。与传统软件漏洞不同，智能合约中的业务逻辑漏洞往往更加隐蔽：程序代码本身可以正常运行，但在特定交易顺序、状态变化或多个功能相互调用时，却可能违背原本的业务规则，导致资产损失。  
  
  
针对这一挑战，360联合清华大学提出智能合约逻辑漏洞检测技术RcAudit，其核心思路是“让AI 既看懂规则，也看清真实执行”：先用大模型读懂合约的业务规则，明确合约“本该怎么做”；再模拟真实交易，主动构造各种交易组合和状态变化去“试探”，看合约有没有跑偏；最后结合真实执行轨迹，验证异常行为是否真的违背规则，从而精准锁定漏洞。简单说，RcAudit 不是只给合约“翻代码体检”，而是带着业务规则“上路实测”，在复杂交易场景中找出真正的违规行为。  
  
实践数据      
  
实践数据显示，在已知漏洞数据集测试中，RcAudit 成功检测出   
132   
个历史逻辑漏洞中的   
74   
个，漏洞检测数量较表现最优的对比工具提升   
117.6%  
，同时在未知漏洞的检测中准确率达到   
96.9%  
。  
  
据了解，RcAudit的实战能力已沉淀在360 图龙锋中。截至目前，360图龙锋已累计挖掘漏洞超过15000个，其中300多个获国家信息安全漏洞库等权威机构核验确认，包括OpenAI Codex、Claude Code、Hermes、OpenClaw等主流商用及开源AI产品中的多项严重、高危级漏洞，服务覆盖政府监管、金融、互联网、网络安全、信创、通信、能源电力、汽车等重点领域。
