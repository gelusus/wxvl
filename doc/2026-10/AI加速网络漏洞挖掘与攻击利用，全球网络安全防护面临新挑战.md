- **赛门铁克揭露了用于自主网络攻击的人工智能代理劫持模型**  
  
安全研究人员发现了一种新型人工智能代理，该代理可无需人工干预即可执行完整的网络攻击。该代理旨在利用被劫持的人工智能模型，在无需人工批准的情况下自主执行多达10万次恶意操作，包括扫描目标、利用漏洞、窃取凭据。  
  
来源: Info Security Magazine  
  
  
- **英国法律援助署数据泄露事件比报道的更为严重，泄露的记录可追溯至1978年**  
  
英国法律援助署发生数据泄露事件，导致服务提供商的企业信息及申请人的个人信息遭泄露。此次泄露涉及联系方式、出生日期、国民身份证号码、犯罪记录、就业状况、缴费金额、债务及付款记录等信息。  
  
来源: CPO Magazine  
  
  
- **GitLab 修复了 10.0 版本中一个关键的远程代码执行（RCE）漏洞，该漏洞允许未经身份验证的远程代码执行**  
  
GitLab已发布紧急安全更新，以修复一个关键的远程代码执行漏洞，该漏洞编号为CVE-2026-110264，CVSS评分达到最高值10.0，影响GitLab社区版和企业版。受影响版本范围可追溯至GitLab 7.0版本，该公司发布了补丁。  
  
来源: GBHackers  
  
  
- **新墨西哥州隐私裁决令Meta面临250亿美元罚款**  
  
据周三公布的新墨西哥州法院文件显示，Meta因近10年前曝光的“剑桥分析”丑闻中涉及的数据隐私违规行为，必须支付250亿美元罚款。此案与Meta旗下的Facebook有关，后者曾向剑桥分析公司共享多达8700万名用户的数据。  
  
来源: The Record  
  
  
- **日本Onamae Desktop Cloud遭黑客攻击，多达27000台服务器受影响**  
  
黑客入侵了日本知名VPS服务提供商Onamae Desktop Cloud的基础设施，并在多达26739台客户服务器上植入了恶意软件。该公司于10月20日证实，未经授权的第三方在部分客户环境中安装了“恶意程序”。  
  
来源: BleepingComputer  
  
  
- **FortiSIEM 一个关键漏洞已出现公开的 PoC 利用代码，可实现未经身份验证的远程代码执行**  
  
网络安全研究人员发布了一个概念验证（PoC）漏洞利用程序，该漏洞（CVE-2026-106173，CVSS评分：9.4）是一种关键的路径遍历漏洞，可能允许未经身份验证的攻击者执行未经授权的代码或命令。  
  
来源: The Hacker News  
  
  
- **GhostAction 攻击者在 94 个 GitHub 仓库中植入了伪装成字体的凭据窃取程序**  
  
GhostAction 供应链攻击背后的威胁行为者已经不再局限于将恶意 GitHub Actions 工作流注入到受感染的项目中，而是开始钓鱼开源开发者，并传播伪装在虚假字体文件中的窃取恶意软件。目前已发现 94 个包含第二阶段组件的受感染代码库。  
  
来源: The Hacker News
