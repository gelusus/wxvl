**D-Link DIR-868L 命令注入漏洞**  
  
发布日期：2026-10-14  
  
受影响系统：  
  
D-Link DIR-868L 2.01b05版本  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CNVD-2026-110536  
  
D-Link DIR-868L是中国D-Link公司的一款实现无线网络接入与多设备共享的路由器。  
  
D-Link DIR-868L 2.01b05版本存在命令注入漏洞，该漏洞源于HNAP CGI Handler组件中文件/htdocs/cgibin的system函数对参数SOAPACTION处理不当，可能导致os命令注入，攻击者可远程发起攻击。  
  
链接：  
  
https://www.dlink.com/  
  
建议：  
  
厂商暂未发布了漏洞修复程序，请及时关注更新:  
  
https://www.dlink.com/  
  
**DataEase SQL注入漏洞**  
  
发布日期：2026-10-14  
  
受影响系统：  
  
DataEase 2.10.26之前版本  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2026-104142  
  
DataEase是DataEase组织开源的一个开源的数据可视化分析工具。用于帮助用户快速分析数据并洞察业务趋势,从而实现业务的改进与优化。  
  
DataEase 2.10.26之前版本存在SQL注入漏洞，该漏洞源于经过身份验证的用户可在数据集分组字段分箱定义中存储特制的FieldGroupDTO.min、FieldGroupDTO.max、FieldGroupDTO.startTime或FieldGroupDTO.endTime值，Utils.transGroupFieldToSql未经验证即将这些自由格式值插入生成的CASE表达式，可能导致存储型SQL注入，危害后端数据库的机密性、完整性和可用性。  
  
链接：  
  
https://github.com/dataease/dataease/releases/tag/v2.10.26  
  
建议：  
  
厂商已发布了漏洞修复程序，补丁获取链接https://github.com/dataease/dataease/security/advisories/GHSA-gcr3-cj2q-gj4q  
  
**TP-Link Omada Software Controller (Windows) 授权问题漏洞**  
  
发布日期：2026-10-14  
  
受影响系统：  
  
TP-Link Omada Software Controller (Windows) 6.3.0.45之前版本  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2026-102298  
  
TP-Link Omada Software Controller (Windows)是中国TP-Link公司的一款网络设备集中管理与监控软件。  
  
TP-Link Omada Software Controller (Windows) 6.3.0.45之前版本存在授权问题漏洞，该漏洞源于MSP模式下用户确认端点未执行所需的权限检查，攻击者可提供可控的Identifier参数验证其他账户凭据，可能导致用户枚举、凭据验证以及未授权访问MSP资源或账户被破解。  
  
链接：  
  
https://support.omadanetworks.com/us/document/136187/  
  
建议：  
  
厂商已发布了漏洞修复程序，补丁获取链接：https://support.omadanetworks.com/us/document/136187/  
  
**Dell Unisphere for PowerMax vApp 命令注入漏洞**  
  
发布日期：2026-10-14  
  
受影响系统：  
  
Dell Unisphere for PowerMax vApp 9.2.4.x版本  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2026-101215  
  
Dell Unisphere for PowerMax vApp是美国Dell公司的一款企业级存储管理软件。  
  
Dell Unisphere for PowerMax vApp 9.2.4.x版本存在命令注入漏洞，该漏洞源于OS命令中特殊元素中和不当，容易受到OS命令注入攻击，可能导致具有远程访问权限的高特权攻击者执行远程命令。
