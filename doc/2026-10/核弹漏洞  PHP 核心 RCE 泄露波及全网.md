补丁未发、细节先泄：PHP 核心两个 9.2 级 RCE，波及 5.4 起全版本，今晚 22:00 补丁发布，修复必须做在基础设施层。  
  
## 01  这不是一次常规披露  
  
PHP 核心两个远程代码执行漏洞   
CVE-2026-109618  
 与   
CVE-2026-109619  
，原本处于 embargo 状态，定于协调披露日随安全更新一起公布。结果 10 月 20 日晚，细节提前泄露上了 Hacker News，一款名为   
php2shell  
 的利用工具截图同步流出，横幅声称对 5.4.0 起的每一个 PHP 版本都有效。PHP 安全团队被迫提前官宣：紧急安全更新定于 10 月 21 日 22:00（北京时间）发布。  
  
也就是说，从泄露到补丁落地，全世界有一整天的攻击窗口。安全团队已确认漏洞真实存在并成功复现了其中一个，而官方明确预警：如果细节扩散或攻击开始，补丁可能提前发布——言下之意，默认攻击随时会开始。每一位运维 PHP 站点的人，今晚都不能睡安稳觉。

## 03  现在知道什么，还不知道什么  
  
技术成因还没公开。官方通告只确认了两点：RCE 无疑、评级 9.2，完整技术细节会随补丁一起发布。泄露流出的只有 php2shell 工具截图，作者署名 Calif.IO，横幅写着支持 PHP 5.4.0 及以上全部版本。  
  
这不代表威胁可以打折。恰恰相反：截图能流出，说明利用链已经工程化；能提前泄露，说明拿到信息的圈子不止一个。从 5.4 到 8.x 跨越十二年的版本线全部命中，这在 PHP 历史上是空前的量级。  
  
## 04  影响范围  
  
所有跑 PHP 的 Web 服务器都在射程内：Magento、Shopware、WooCommerce 等电商站只是最典型的靶子，包括国内大量自建站、内部系统、API 后端。更麻烦的是修复方式——漏洞在 PHP 自身，补丁只能通过升级服务器上的 PHP 来打，改应用代码、加应用层规则都没用。  
  
还有一批最危险的存量：PHP 官方只维护   
8.2  
 及以上版本，8.1 及更老的版本根本不会有官方补丁。这些服务器要么升上去，要么下线，没有第三条路。  
  
## 05  利用分析  
  
在官方细节公布前，只能做危害推演。RCE 打在 PHP 核心层，意味着攻击发生在应用代码运行之前，WAF 规则和业务层防护拦不住它——这是这次事件最要命的一点。一旦完整利用代码随补丁发布流出，脚本小子和勒索团伙会在数小时内完成武器化，业界预期补丁发布后 15 分钟内就会开始大规模扫描攻击。  
  
对红队来说，这类漏洞的实战价值无需多言：命令执行直接落在 Web 进程上下文，拿到的是 php-fpm 或 httpd 权限，内网横向的起点就此建立。今晚补丁发布后，第一时间确认利用细节是否公开，再决定后续动作。  
  
## 06  检测与排查  
  
在补丁落地前，监控重点是 PHP 工作进程有没有异常拉起子进程。正常业务里   
php-fpm  
、  
php-cgi  
 不会去启动 shell、解释器或下载工具，出现即是强信号。  
  
auditctl -a always,exit \  
  
  -F arch=b64 -S execve \  
  
  -k php_exec  
  
ausearch -k php_exec --start today \  
  
  | grep -E 'bash|sh$|curl|wget'  
  
没有 auditd 的环境，退而在 EDR 或日志平台上建规则：php-fpm、php-cgi、httpd、apache2 任一进程的子进程名单里出现 sh、bash、cmd.exe、powershell、python、curl、wget，立即告警。补丁发布后官方技术细节会给出更精确的检测思路，届时再补规则。  
  
## 07  修复建议  
  
今晚 22:00 补丁一发布就升级，这是唯一可靠的修复。自己管服务器的，提前把升级流程演练好；托管在云厂商或虚拟主机上的，今天就联系服务商让他们待命，补丁一出立刻升。  
  
8.1 及更老的版本没有官方补丁，处置只有三条：升级到受支持版本、暂时下线、或者收进内网挂 WAF 挡在前面。但要清楚一件事：这次攻击发生在 PHP 层，WAF 只能算临时止血，不能当修复方案。  
  
## 08  红队视角  
  
按经验，这种全版本 PHP 核心 RCE 的杀伤半径不会小于 Log4j：互联网上 PHP 站点的存量太大，而能在一个工作日内完成核心升级的运维团队是少数。接下来几天大概率会看到：利用代码公开、批量扫描、僵尸网络抓鸡、勒索软件落地，一条龙走完。  
  
给防御侧的排序建议：今晚升级高于一切；升级不了的先断公网；监控 PHP 进程树异常；电商和暴露面大的站点优先处理。补丁发布后如果官方细节里有新的利用条件或缓解参数，第一时间重估风险。
