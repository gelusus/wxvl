#  HPE Aruba AOS-8 存在严重漏洞，黑客可绕过 SSH 身份验证并接管系统  
原创 ZM
                    ZM  暗镜   2026-10-29 22:00  
  
惠普企业（HPE）已修复其 AOS-8 无线操作系统中的 SSH 守护程序中存在一个严重的身份验证绕过漏洞。  
  
该漏洞编号为 CVE-2026-79855，可能允许远程未经身份验证的攻击者获得管理权限并完全控制受影响的主机。该漏洞的 CVSS v3.1 评分为 9.8，表明其严重性极高。攻击者无需凭证或用户交互，即可在网络复杂度较低的环境中利用此漏洞，从而显著影响机密性、完整性和可用性。  
  
HPE公司将此问题归功于其内部网络安全研究人员的发现。更详细的安全公告HPESBNW05162于2020年10月22日发布，其中详细介绍了SSH漏洞6。该公告记录了 AOS-8 和 AOS-10 中的 72 个漏洞，包括身份验证绕过、命令和 SQL 注入、缓冲区溢出、内存损坏、路径遍历、信息泄露、跨站脚本攻击、文件篡改和拒绝服务攻击。这些漏洞中有好几个获得了最高的 CVSS 评分 10.0，并且允许未经身份验证的远程代码执行。  
  
受影响的软件版本包括受支持分支中的 AOS-10 10.8.1.1 及更早版本、10.7.2.6 及更早版本以及 10.4.1.13 及更早版本。运行 8.13.3.0 及更早版本或 8.10.0.23 及更早版本的 AOS-8 系统也存在漏洞。受影响的设备包括兼容的移动通信控制器、移动通信网络控制器、集中管理的移动通信网关、AOS-10 接入点、AOS-8 Instant 接入点以及相关的虚拟部署。攻击者可以利用各种漏洞获取特权控制权、篡改无线配置、访问敏感数据、破坏文件系统、中断网络服务或在底层操作系统上执行代码。其中，PAPI接入点管理协议存在的问题尤其令人担忧。  
  
例如，CVE-2026-79860 利用精心构造的数据包攻击 UDP 端口 8211。其他 PAPI 漏洞也允许命令注入、SQL 注入、缓冲区溢出或身份验证绕过。强烈建议管理员立即升级到 AOS-10 10.8.1.2、10.7.2.7 或 10.4.1.14 版本，具体取决于其版本分支。AOS-8 用户应更新至 8.13.3.1 或 8.10.0.24 版本。HPE 表示，在发布公告时，他们并不知道有任何与这些漏洞相关的公开讨论或利用代码，但强调由于这些漏洞的范围广、复杂性高且潜在影响大，因此需要迅速进行修补。  
  
如果无法立即进行升级，HPE 建议将命令行和 Web 管理界面隔离在专用的二层网段或 VLAN 上，强制执行三层或更高层的防火墙控制，并实施计费机制来跟踪和记录用户活动和资源使用情况。虽然这些措施可以降低风险，但并不能取代厂商提供的修复程序。
