漏洞与攻击  
  
pH7Builder 旧版本存在硬编码 API 密钥绕过漏洞  
  
安全研究人员披露 pH7Builder（pH7 Social Dating CMS）在 18.6.0 之前的版本中存在硬编码 API 密钥漏洞。该漏洞位于 Tool.class.php 文件中，允许未经身份验证的攻击者通过伪造 Host 头部绕过 API 访问检查。攻击者可发送 Host: localhost 并附带 private_api_key=dev772277 和默认允许的 URL，从而检索成员电子邮件、IP 地址、电话号码和银行账户字段。该漏洞严重性评级为 8.7（高危）。  
  
来源：cvefeed · 10-11 23:16（北京时间）  
  
漏洞与攻击  
  
JeecgBoot存在权限绕过漏洞  
  
安全研究人员发现JeecgBoot存在严重漏洞，影响版本至3.9.5。该漏洞位于SysDepartRoleController组件的saveDatarule函数，攻击者通过操纵permissionId/roleId/dataRuleIds参数可导致权限验证缺失。该漏洞被编号为CVE-2026-108871，目前已知可进行远程攻击，但尚未有公开利用代码。  
  
来源：vuldb · 10-11 23:02（北京时间）  
  
漏洞与攻击  
  
Netcore NR268存在严重认证缺陷  
  
Netcore NR268 1.7.121109版本被发现存在非常严重的漏洞，位于CGI Execution组件的user_ok函数。攻击者通过特定操作可导致 improper authentication（不正确的身份验证）。该漏洞被编号为CVE-2026-108907，攻击者可远程发起攻击，且已存在可利用的漏洞利用程序。厂商在披露早期已收到通知但未回应。  
  
来源：vuldb · 10-11 23:00（北京时间）  
  
漏洞与攻击  
  
JeecgBoot存在权限管理缺陷  
  
JeecgBoot存在严重漏洞，影响版本至3.9.5。该漏洞位于Save Datarule Handler组件的saveDatarule函数，攻击者通过操纵permissionId/roleId/dataRuleIds参数可导致 improper privilege management（不正确的权限管理）。该漏洞被编号为CVE-2026-108870，攻击者可远程发起攻击，目前尚未有公开利用代码。  
  
来源：vuldb · 10-11 23:00（北京时间）  
  
漏洞与攻击  
  
Netcore NR268 1.7.121109存在远程越界读取漏洞  
  
研究人员发现Netcore NR268 1.7.121109设备中的filter_arp_put_file.cgi文件存在严重漏洞，攻击者可通过远程操纵put_file参数触发越界读取。该漏洞被标记为CVE-2026-108906，目前已有可用的利用程序。  
  
来源：vuldb · 10-11 23:00（北京时间）
