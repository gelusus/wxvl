1. Google Chrome 资源管理错误漏洞（CNNVD-2026-97813474）  
  
Google Chrome是美国Google公司的一个跨平台Web浏览器。  
  
Google Chrome 156.0.8078.47之前版本存在资源管理错误漏洞，该漏洞源于内存释放后重用问题，攻击者利用该漏洞可以通过特制的HTML页面在沙箱外执行任意代码。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://chromereleases.googleblog.com/2026/10/stable-channel-update-for-desktop_02018666648.html  
  
2. Apache CouchDB 资源管理错误漏洞（CNNVD-2026-75220766）  
  
Apache CouchDB是美国Apache基金会的一款服务端软件产品。  
  
Apache CouchDB 3.5.2及之前版本存在资源管理错误漏洞，该漏洞源于在gzip解压缩过程中没有限制解压缩大小，攻击者利用该漏洞可以通过耗尽内存导致系统拒绝服务。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://lists.apache.org/thread.html/pj83174r8f8f64odf47fwhozbfjtot0f

## 五重大漏洞通报  
  
  
**CNNVD关于PHP 操作系统命令注入漏洞的通报**  
  
近日，国家信息安全漏洞库（CNNVD）收到关于PHP 资源管理错误漏洞（CNNVD-2026-75300632、CVE-2026-109618）（CNNVD-2026-41545346、CVE-2026-109619）情况的报送。成功利用漏洞的攻击者，可通过构造恶意 HTTP 请求实现内存泄露，进而远程执行代码。PHP多个版本均受此漏洞影响。目前，PHP官方已发布新版本修复了该漏洞，建议用户及时确认产品版本，尽快采取修补措施。  
  
1.漏洞介绍  
  
  
PHP是PHP团队开源的一种在服务器端执行的脚本语言。PHP存在资源管理错误漏洞，其中（CNNVD-2026-75300632、CVE-2026-109618）源于使用longjmp()处理内存时错误，导致请求内存在分配前处于未初始化状态。（CNNVD-2026-41545346、CVE-2026-109619）源于PHP在全局状态请求结束后未正确重置，使后续请求在正常初始化之前访问已释放的请求内存。未经认证的攻击者可利用漏洞，通过构造恶意 HTTP 请求实现内存泄露，进而远程执行代码。     
  
2.危害影响  
  
  
PHP 8.2.35版本之前的8.2.x版本、8.3.36版本之前的8.3.x版本、8.4.27版本之前的8.4.x版本和8.5.12版本之前的8.5.x版本均受此漏洞影响。  
  
3.修复建议  
  
  
目前，PHP官方已发布新版本修复了该漏洞，建议用户及时确认产品版本，尽快采取修补措施。官方参考链接：  
  
https://github.com/php/php-src/security/advisories/GHSA-w8hw-w9fx-j79w  
  
https://github.com/php/php-src/security/advisories/GHSA-6wmf-4rv5-p3rp
