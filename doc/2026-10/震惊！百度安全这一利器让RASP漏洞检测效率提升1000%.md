重点导读概述
使用该测试环境前，请务必确保所有操作均在合法授权的测试环境中进行。未经授权对任何系统进行安全测试可能违反相关法律法规。
OpenRASP Cloud 自动化测试环境是一套基于 Docker Compose 构建的集成化测试平台，专注于 RASP（Runtime Application Self-Protection）技术验证。该环境覆盖 PHP、Java 两大主流语言版本，支持 Apache、Nginx、Tomcat 等多种 Web 服务器，通过模拟真实攻击场景验证 RASP 防护效能。

PART 09已知问题
LRU 机制会影响部分测试结果。sql 类和 ssrf 类检测使用 LRU 缓存，可能导致插件更新测试结果出现偏差，不宜选作测试用例。
