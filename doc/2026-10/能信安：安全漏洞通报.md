**Microsoft Office Word 缓冲区错误漏洞**  
  
发布日期：2026-10-13  
  
受影响系统：  
  
Microsoft 365 Apps for Enterprise  
  
Microsoft Office LTSC 2024  
  
Microsoft Office LTSC 2021  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2026-70300  
  
Microsoft Office Word是美国Microsoft公司的一款文字处理软件。  
  
Microsoft Office Word存在缓冲区错误漏洞，该漏洞源于不可信指针取消引用，可能导致未经授权的攻击者通过网络执行代码。  
  
链接：  
  
https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-70300  
  
建议：  
  
厂商已发布了漏洞修复程序，补丁获取链接:  
  
https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-70300  
  
  
**Microsoft Win32K 资源管理错误漏洞**  
  
发布日期：2026-10-13  
  
受影响系统：  
  
Win32K  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2026-83762  
  
Microsoft Win32K是美国Microsoft公司的一个操作系统核心内核组件。  
  
Microsoft Win32K存在资源管理错误漏洞，该漏洞源于Windows Win32K中存在释放后重用问题，可能导致经过身份验证的攻击者在本地提升权限。  
  
链接：  
  
https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-83762  
  
建议：  
  
厂商已发布了漏洞修复程序，补丁获取链接：  
  
https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-83762  
  
  
**Mozilla Firefox 竞争条件问题漏洞**  
  
发布日期：2026-10-13  
  
受影响系统：  
  
Mozilla Firefox 158之前版本  
  
Mozilla Firefox ESR 115.43之前版本  
  
Mozilla Firefox ESR 153.5之前版本  
  
Mozilla Thunderbird 158之前版本  
  
Mozilla Thunderbird 153.5之前版本  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2026-109719  
  
Mozilla Firefox是Mozilla基金会开源的一款网页浏览器。  
  
Mozilla Firefox 158之前版本、Mozilla Firefox ESR 115.43之前版本、Mozilla Firefox ESR 153.5之前版本、Mozilla Thunderbird 158之前版本和Mozilla Thunderbird 153.5之前版本存在安全漏洞，该漏洞源于Graphics: CanvasWebGL组件存在竞争条件和释放后重用，可能导致内存损坏。  
  
链接：  
  
https://www.mozilla.org/security/advisories/mfsa2026-106/  
  
建议：  
  
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www.mozilla.org/security/advisories/mfsa2026-106/  
  
  
**Microsoft Windows SmartScreen 路径遍历漏洞**  
  
发布日期：2026-10-13  
  
受影响系统：  
  
Microsoft Windows 11 Version 24H2  
  
Microsoft Windows 11 Version 26H2  
  
Microsoft Windows 11 Version 25H2  
  
Microsoft Windows 11 version 26H1  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2023-108463  
  
Microsoft Windows SmartScreen是美国Microsoft公司的一款可检查应用与下载的信誉并提醒用户防范潜在恶意内容的安全防护功能。  
  
Microsoft Windows SmartScreen存在路径遍历漏洞，该漏洞源于路径等价解析不当，可能导致未经身份验证的攻击者通过网络安全功能绕过。  
  
链接：  
  
https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-108463  
  
建议：  
  
目前厂商暂未发布升级补丁以修复漏洞，请及时关注更新：https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-108463
