- **印度国家银行（SBI）37W客户数据泄露事件**  
  
2026年10月，黑客声称泄露印度国家银行37万条客户数据，实际路径为攻击者利用公网API对象级越权与批量枚举，通过低频慢速采集与代理轮换持续6天拉取数据，涉及11万唯一手机号用户，属真实金融客户数据外泄事件。  
  
来源: CN-SEC 中文网  
  
  
- **OpenCode 黑客事件在 AI 蒸馏攻击中泄露了 API 密钥**  
  
OpenCode宣布它遭受了大规模的蒸馏攻击，仅影响了链接外部提供商的开发人员，包括Anthropic，OpenAI和Google。此次违规行为影响了1.4％的OpenCode控制台用户，其中一些人在一夜之间报告了超过$1700的未经授权费用。  
  
来源: BleepingComputer  
  
  
- **F5 发布了针对 NGINX 关键漏洞的带外补丁**  
  
F5 已发布带外安全补丁，以修复多个 NGINX Web 服务器漏洞，其中包括三个严重级别的漏洞，这些漏洞可能使攻击者在存在漏洞的系统上执行代码。涉及CVE-2026-15176、CVE-2026-97205和CVE-2026-93479三个漏洞。  
  
来源: BleepingComputer  
  
  
- **Bullhorn 将招聘平台转为离线模式以遏制网络攻击**  
  
人力资源软件公司Bullhorn已暂停其平台的访问，以遏制一次导致全系统瘫痪的网络攻击。该公司表示，已将问题隔离并消除了直接威胁。目前，其团队正在与CrowdStrike专家合作，在完成全面的安全审查后，努力恢复服务。  
  
来源: BleepingComputer  
  
  
- **日本SiteGuard WAF的漏洞CVE-2026-106931目前已被利用**  
  
EG Secure Solutions发布紧急警报，警告SiteGuard Server Edition存在OS命令注入漏洞（CVE-2026-106931），攻击者已在实际环境中利用。成功利用后可在服务器上以root或SYSTEM权限执行命令。  
  
来源: Security Affairs  
  
  
- **加州数百万学生的敏感数据在一次数据泄露事件中被盗**  
  
教育考试服务处（ETS）运营的一个系统中，数百万名加州公立学校在校生和往届学生的个人信息遭窃。此前，有未经授权的第三方访问了ETS运营的安全文件传输协议（SFTP）站点，并复制了学生信息。  
  
来源: MalwareBytes Blog

一个虚假的 Web3 加速器以提供 Anthropic Claude 和 Google Gemini 的免费人工智能（AI）积分、编码工具及安全审计为幌子，利用恶意 npm 包向 Windows 和 macOS 系统植入信息窃取程序和后门。
