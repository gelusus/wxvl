#  IBM 修补 23 个 DataPower Gateway 漏洞，其中包括四个严重的远程代码执行和 XSS 漏洞  
sec随谈
                    sec随谈  sec随谈   2026-10-09 01:17  
  
**内容摘要**  
  
IBM 通过两份安全公告发布了针对 23 个 IBM DataPower Gateway 漏洞的修复程序。其中四个被评为严重级，包括两个评分为 9.8、无需登录即可利用的远程代码执行漏洞。IBM "强烈建议尽快升级"。  
  
**为何值得关注**  
  
DataPower Gateway 是 IBM 面向 API、Web 服务和企业间（B2B）流量的安全与集成设备，通常部署在网络边缘、受保护系统的前端。因此，网关中的漏洞可能会暴露其本应保护的系统。  
  
这些漏洞大多无需凭据即可通过网络触发。在 23 个漏洞中，IBM 将 4 个评为严重级，17 个为高危级，2 个为中危级。CVE 记录将漏洞利用状态列为未知，且尚未确认存在公开的概念验证代码。  
  
**攻击原理**  
  
**远程代码执行**  
  
CVE-2026-15762  
 和   
CVE-2026-16340  
 的评分均为 9.8。两者都可能"因越界写入而允许远程攻击者执行任意代码"。第二个漏洞存在于 RFC 2047 编码字解析器中，该解析器负责解码邮件格式标头中的文本。与此同时，  
CVE-2026-15784  
（8.1）和   
CVE-2026-15781  
（8.0）也是代码执行漏洞，但两者的触发难度更高。  
  
**令人困惑的第四个严重级漏洞**  
  
CVE-2026-14991  
 同样是评分为 9.8 的越界写入漏洞。然而，其描述称"本地用户可以使缓冲区溢出并在系统上执行任意代码"，这与其基于网络的 CVSS 向量相矛盾。无论如何，这都是将这些 IBM DataPower Gateway 漏洞视为紧急事项的又一个理由。  
  
**Web UI 跨站脚本**  
  
另一份公告  
涉及评分为 9.3 的   
CVE-2026-14990  
。该漏洞允许未经身份验证的用户"在 Web UI 中嵌入任意 JavaScript 代码"。据 IBM 称，这可能导致"在受信任会话中泄露凭据"。该漏洞仅影响 10.6.0 分支。  
  
**崩溃与数据泄露**  
  
其余大部分 IBM DataPower Gateway 漏洞会导致拒绝服务，其根源包括缓冲区溢出、空指针解引用、类型混淆和越界读取，其中两个涉及 GraphQL 处理。此外，  
CVE-2026-16181  
 允许攻击者绕过安全限制，  
CVE-2026-16177  
 则可能泄露敏感数据。  
  
**受影响版本**  
  
IBM 主安全公告  
列出了以下受影响版本：  
- 10.5.0.0 至 10.5.0.22，已在 10.5.0.23 中修复  
  
- 10.6.0.0 至 10.6.0.10，已在 10.6.0.11 中修复  
  
- 10.6.1 至 10.6.6（10.6CD），已在 11.0.0.3 中修复  
  
- 11.0.0.0 至 11.0.0.2，已在 11.0.0.3 中修复  
  
**补丁与缓解措施**  
  
请升级至您所用分支的修复版本。CVE 记录未列出针对这些漏洞的任何临时解决方案。处于 10.6CD 持续交付通道的用户必须迁移至 11.0.0.3。此外，在补丁到位之前，请将 DataPower Web UI 的访问权限限制在可信管理员范围内。
