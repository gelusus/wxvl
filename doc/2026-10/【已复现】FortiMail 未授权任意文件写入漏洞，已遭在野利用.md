#  【已复现】FortiMail 未授权任意文件写入漏洞，已遭在野利用  
原创 360漏洞研究院
                    360漏洞研究院  360漏洞研究院   2026-10-11 01:00  
  
Fortinet FortiMail 曝出严重未认证任意文件写入漏洞（CVE-2026-104286，CVSS 3.1：9.8）。未经身份认证的远程攻击者可通过构造特制 HTTP 或 HTTPS 请求，利用路径限制不当及 NULL 字节处理缺陷，将任意文件写入底层系统非预期位置。Fortinet 已确认该漏洞存在在野利用。  
  
  
**利用前置条件：**  
- 攻击者能够通过网络访问目标 FortiMail 相关 Web 接口  
  
**目前360图龙锋 · 漏洞挖掘智能体已成功复现该漏洞。**  
本文包含完整影响范围、正式修复方案、技术原理与复现细节。

**01**  
  
**漏洞影响范围**  
  
  
  
CVE-2026-104286 影响 Fortinet FortiMail 的以下版本：  
  
FortiMail 8.0：8.0.0 ～ 8.0.1（< 8.0.2）  
  
FortiMail 7.6：7.6.0 ～ 7.6.6（< 7.6.7）  
  
FortiMail 7.4：7.4.0 ～ 7.4.8（< 7.4.9）  
  
FortiMail 7.2：7.2.0 ～ 7.2.9  
  
  
**02**  
  
**修复建议**  
  
  
  
**正式防护方案**  
  
根据 Fortinet 官方安全公告，建议升级到以下 FortiMail 版本以修复 CVE-2026-104286 漏洞：  
  
FortiMail 8.0：>= 8.0.2  
  
FortiMail 7.6：>= 7.6.7  
  
FortiMail 7.4：>= 7.4.9  
  
FortiMail 7.2：升级至已修复的 7.4 或更高版本。  
  
  
对于暂时无法升级的设备，建议关闭 Identity-Based Encryption（IBE）功能，并限制 FortiMail 管理接口的互联网访问，仅允许可信网络访问。  
  
  
**03**  
  
**漏洞描述**  
  
  
  
2026年10月1日，Fortinet 公布了影响 FortiMail 邮件安全网关的未授权任意文件写入漏洞（CVE-2026-104286），漏洞严重程度为 Critical（CVSS 9.8）。该漏洞涉及 FortiMail 的身份加密（Identity-Based Encryption，IBE）功能，根源在于 Web 请求处理过程中存在路径遍历（Path Traversal）和 NULL 字节处理缺陷。系统在处理攻击者可控的文件路径时，未能正确限制目标文件的写入目录，且对 NULL 字节的处理可能导致路径校验与实际文件操作结果不一致，从而使攻击者能够绕过目录边界限制，将文件写入预期目录之外的位置。  
  
  
攻击者无需身份认证，即可向存在漏洞且相关 Web 接口可访问的 FortiMail 设备发送特制的 HTTP/HTTPS 请求。攻击者通过构造包含目录遍历字符及 NULL 字节的恶意请求，利用文件路径校验缺陷，使服务端将攻击者控制的内容写入非预期的文件系统位置。若能够覆盖关键系统文件或向可执行目录写入恶意程序，则可能进一步实现远程代码执行（RCE），最终控制 FortiMail 设备。该漏洞已被证实存在野外利用，Fortinet 建议及时升级受影响版本，或临时关闭 IBE 功能以降低攻击风险。  
  
  
**04**  
  
**漏洞复现**  
  
  
  
360漏洞研究院依托图龙锋漏洞挖掘智能体已成功复现 CVE-2026-104286。在受影响版本的 FortiMail 环境中，向相关 Web 接口发送经过构造的请求后，将测试文件写入预期目录之外的位置，验证了该漏洞未认证任意文件写入风险。
