#  Oracle发布1295个安全补丁，修复多个产品中的关键漏洞  
ZM
                    ZM  暗镜   2026-10-25 22:00  
  
Oracle 发布了 2026 年 10 月关键补丁更新，其中包含针对其企业产品组合的 1295 个全新安全补丁。该更新于 10 月 20 日发布，旨在解决Oracle 软件以及第三方组件中的漏洞。  
  
值得注意的是，它修复了攻击者无需身份验证即可远程利用的关键漏洞。受影响的产品包括数据库、中间件、业务应用程序、Java、MySQL 和虚拟化平台。  
  
Oracle 警告称，攻击者仍在试图利用已有补丁程序修复的漏洞。据报道，一些攻击之所以成功，是因为客户未能安装必要的修复程序，这凸显了及时修复漏洞和保持软件版本持续受支持的重要性。  
  
Oracle APEX 已收到两个补丁，其中包括 CVE-2026-101521，该漏洞评分为 9.8。此漏洞存在于通用组件中，允许攻击者通过 HTTPS 进行未经身份验证的网络攻击，攻击复杂度低，且无需用户交互。该漏洞影响 APEX 版本 24.1.0–24.1.21、24.2.0–24.2.20 和 26.1.0–26.1.4。  
  
第二个 APEX 问题 CVE-2026-66010 影响捆绑的 DOMPurify 组件，其 CVSS 评分为 6.1。与严重的 APEX 漏洞不同，利用此漏洞需要用户交互，这表明管理员应该评估每次攻击的前提条件，而不是一概而论地对待每个补丁。  
  
Oracle Essbase 已收到 38 个补丁，修复了 14 个无需身份验证即可被远程利用的漏洞。其中四个安全漏洞（CVE-2026-91637、CVE-2026-91638、CVE-2026-91658 和 CVE-2026-91663）的 CVSS 评分为 9.9，影响版本 21.8.3.0.0。  
  
这些漏洞只需较低的权限即可利用，无需用户交互，其利用途径涉及 HTTP 或 T3/IIOP；Oracle 指出，这些漏洞会对机密性、完整性和可用性造成严重影响。此外，CVE-2026-91665 的评分为 9.8，允许通过 TCP 进行未经身份验证的网络攻击。Oracle Autonomous Health Framework 也收到了五个补丁。其与 OpenSSL 相关的 CVE-2026-75803 漏洞评分为 9.1，影响版本 26.3 至 26.8，这表明同一个 CVE 漏洞在不同的产品环境中可能具有不同的严重性评级。  
  
安全团队应将已部署的版本与 Oracle 受影响的产品表进行比对，并审查每个适用的风险矩阵。此处提到的 1295 指的是安全补丁的数量，并非一定是唯一的漏洞；Oracle 指出，同一个 CVE 可能出现在多个产品矩阵中。  
  
Oracle 建议尽快应用补丁。临时措施可能包括阻止漏洞利用所需的协议或移除不必要的权限和软件包访问权限。但是，这些控制措施可能会中断应用程序，需要在生产环境之外进行测试，并且无法修复根本漏洞。  
  
之前跳过更新的组织应重新查看之前的安全公告。不受支持的版本未针对这些漏洞进行测试。但是，Oracle 警告称，旧版本仍可能受到影响，并建议升级到受支持的版本，以确保能够持续获得安全补丁。
