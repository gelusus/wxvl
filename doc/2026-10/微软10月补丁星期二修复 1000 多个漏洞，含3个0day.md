- 254  
个信息泄露漏洞  
  
- 73  
个拒绝服务漏洞  
  
- 28  
个欺骗漏洞

**CVE-2026-96951**  
是  
Windows Shell   
安全特性绕过漏洞，已遭活跃利用。早在  
2024  
年，攻击者已通过多种方法绕过  
 MotW   
防护措施。本漏洞虽然与  
 Shell   
有关，但造成的结果仍然是一样的。用户应尽快测试并部署补丁。

 Windows Defender Application Control (WDAC)

 MessagePack-Csharp   
中的一个拒绝服务漏洞，之前由第三方发布，微软本次纳入且并未提到已遭活跃利用。

****  
**CVE-2026-102866**  
是位于  
 Microsoft Office SharePoint   
中的一个提权漏洞。虽然本次修复了多个  
 SharePoint   
漏洞，但该漏洞是唯一一个“严重”级别（  
CVSS 8.1  
分）且可遭未经身份认证攻击者利用的漏洞。该漏洞是一个密码签名验证不当漏洞，获得目标用户有效验证令牌的攻击者均可修改该漏洞，将其提交至服务器并认证为该用户。攻击者唯一需要做的是需要先获取令牌，而获取的方法有很多。  
  
**CVE-2026-65674**  
是位于微软  
 SQL   
服务器中的  
RCE   
漏洞。该漏洞是本次修复的  
CVSS  
评分最高（  
8.8  
）的  
 SQL   
服务器漏洞。该漏洞是对不受信任数据的反序列化漏洞。经身份认证的攻击者连接到受影响的  
 SQL   
服务器并发送特殊构造的请求在服务器上运行代码，即可实施利用，无需任何用户交互。用户应尽快排查直接连接到互联网的任何  
 SQL   
服务器。  
  
**CVE-2026-70571**  
是位于微软  
 Exchange Server   
上的  
RCE   
漏洞。从技术角度来讲，该漏洞是一个蠕虫漏洞。微软表示，“利用要求攻击者深入了解目标环境且不一定会成功。”虽然措辞晦涩，但凑齐利用该漏洞攻击  
 Exchange   
服务器所需的各种条件的可能性微乎其微。
