#  Windows BitLocker漏洞可让攻击者绕过安全防护并实现权限提升  
原创 网络安全9527
                    网络安全9527  安全圈的那点事儿   2026-10-14 10:14  
  
根据安全公告描述，Windows的3个BitLocker漏洞，可让攻击者在不同访问条件下提升权限或者绕过安全防护机制。  
  
   
  
微软为这几个漏洞分配编号，公告发布于2026年10月13日，这3个漏洞全部被标记为重要级别。  
  
   
  
其中两个漏洞需要攻击者已获得本地访问权限，第三个漏洞则需要物理接触设备。本文未能独立访问对应的CVE漏洞记录进行核验。  
  
   
  
Windows BitLocker相关漏洞  
  
   
  
CVE‑2026‑85920：属于权限提升漏洞，对应缺陷类型CWE‑367，即检查时间到使用时间竞争条件（TOCTOU）。  
  
   
  
该漏洞原理：软件先校验资源状态，但在真正使用该资源前，资源状态已经发生改变，致使原先的安全校验失效。这类时间差漏洞会被用于实现未授权访问；不过现有公开资料没有说明受影响的BitLocker具体功能，也未披露漏洞利用流程。  
  
   
  
该漏洞CVSS 3.1评分：基础分7.0，时间分6.1。利用条件：本地访问、低权限，攻击复杂度高，无需用户交互。  
  
   
  
漏洞利用成功后，对保密性、完整性、可用性均会造成严重影响；漏洞作用范围不变，但没有说明攻击者最终可以获取到什么具体权限。  
  
   
  
CVE‑2026‑88070：基础分7.8（本篇报道里分数最高），时间分6.8。同样是本地权限提升漏洞，攻击者只需低权限，不需要用户交互。  
  
   
  
和上面的竞争条件漏洞不同，该漏洞攻击复杂度低。利用成功后对保密性、完整性、可用性均为高危害，作用范围不变。  
  
   
  
该漏洞对应CWE‑125，即越界读取，程序读取超出缓冲区边界的数据。MITRE机构说明，这类缺陷可能泄露敏感内存数据或者造成程序崩溃，具体取决于代码实现。  
  
   
  
但是这份漏洞说明没有解释越界读取如何实现权限提升，也没有给出漏洞利用的技术原理。  
  
   
  
CVE‑2026‑83500：安全功能绕过漏洞，基础分6.1，时间分5.3。利用条件：需要物理接触设备，攻击复杂度低，无需权限，无需用户交互。漏洞利用成功后，严重威胁保密性与完整性，不会影响系统可用性。  
  
   
  
该漏洞被归类到CWE‑601缺陷类型，该类缺陷一般指跳转至不受信任站点的URL重定向问题。MITRE对此类漏洞的定义是：由用户可控输入，把请求重定向到外部地址。  
  
   
  
目前没有解释该缺陷类型与BitLocker绕过之间的关联，因此不能把这个归类当作某种磁盘解锁攻击手段的依据。  
  
   
  
现有公开材料没有写明受影响的Windows系统版本、需要安装哪些更新补丁、临时缓解方案，也没有发现现实中已经发生的攻击案例。  
  
   
  
因此无法确定哪些系统需要修复，也不能确认漏洞已经被实际利用。在对外发布信息或者执行运维操作前，请务必查阅微软官方安全公告核对完整信息。
