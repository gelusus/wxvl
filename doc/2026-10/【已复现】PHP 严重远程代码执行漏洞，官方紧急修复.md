#  【已复现】PHP 严重远程代码执行漏洞，官方紧急修复  
原创 360漏洞研究院

**01**  
  
**漏洞影响范围**  
  
  
  
受影响版本范围：  
  
PHP 8.2 分支 < 8.2.35  
  
PHP 8.3 分支 < 8.3.36  
  
PHP 8.4 分支 < 8.4.27  
  
PHP 8.5 分支 < 8.5.12  
  
PHP 8.1 及更早版本同样可能受到影响，由于这些分支已停止官方常规安全维护，建议升级至受支持版本。  
  
  
**02**  
  
**修复建议**  
  
  
  
**正式防护方案**  
  
升级至对应分支的 PHP 版本或更高的已修复版本  
  
PHP 8.2 分支 >= 8.2.35  
  
PHP 8.3 分支 >= 8.3.36  
  
PHP 8.4 分支 >= 8.4.27  
  
PHP 8.5 分支 >= 8.5.12  
  
  
**03**  
  
**漏洞描述**  
  
  
  
近日，PHP 官方披露了 PHP 核心中存在的两项远程代码执行漏洞（CVE-2026-109618、CVE-2026-109619）。前者与内存不足时的异常中断有关：部分请求数据尚未完成初始化，执行流程即被中断，后续清理可能错误处理无效内存状态。后者涉及跨请求残留的全局状态：一个请求结束后，工作进程仍可能保存指向已释放内存的引用，后续请求在正常初始化之前读取该状态，从而触发释放后使用。研究人员已验证，在不同的部署和应用条件下，这些缺陷可能造成敏感内存泄露或以 Web 工作进程权限执行代码。  
  
  
**04**  
  
**漏洞复现**  
  
  
  
360漏洞研究院已成功复现 CVE-2026-109618、CVE-2026-109619。造成内存损坏，工作进程 SIGSEGV 并产生 core dump。
