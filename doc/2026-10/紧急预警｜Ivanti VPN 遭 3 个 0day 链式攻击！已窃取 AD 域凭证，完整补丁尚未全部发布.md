#  紧急预警｜Ivanti VPN 遭 3 个 0day 链式攻击！已窃取 AD 域凭证，完整补丁尚未全部发布  
原创 维度攻防
                        维度攻防  维度攻防   2026-10-14 08:03  
  
近日，安全厂商 Volexity 披露一则重大安全事件：威胁组织**UTA0576**  
利用**Ivanti Connect Secure VPN 设备上的 3 个零日漏洞**  
进行链式攻击，**无需任何账号密码，直接获取设备 root 最高权限**  
，大肆窃取企业 Active Directory 域敏感凭据，包括 LAPS 管理员密码、BitLocker 恢复密钥等核心资产。  
  
攻击最早从**2026‑10‑03**  
开始，最值得警惕的一点：**遭到入侵的设备本身已经更新到最新补丁版本 22.8R2.4**  
。也就是说，常规的版本更新防护，对这组全新 0 日漏洞完全失效。  
## 攻击拆解：三个 0day 漏洞组合拳  
  
本次漏洞链由 3 个零日缺陷串联而成，其中身份绕过 + 文件写入漏洞统一编号为 **CVE‑2026‑104935**  
，第三个为独立提权漏洞，**该提权漏洞截至目前暂未发布补丁**  
。  
1. **身份认证绕过（CVE‑2026‑104935 组件 1）**  
攻击者向公开登录脚本welcome.cgi  
发送特殊 HTTP 请求，植入X‑DSCGI‑PATH  
请求头，欺骗 VPN 访问受保护的内部脚本，实现无认证访问。  
  
1. **文件写入缺陷（CVE‑2026‑104935 组件 2）**  
滥用设备文件上传处理接口，向设备/tmp  
目录写入恶意脚本。利用设备短暂保留临时文件的时间窗口，高速重复请求执行恶意代码，以cgi‑server  
用户身份拿到初始执行权限。  
  
1. **本地权限提升（第三个未公开 CVE，暂无补丁）**  
攻击者调用 VPN 内部特权服务dsinvoked  
，内存篡改配置，执行攻击者脚本，直接提升至**root 最高权限**  
，执行完成后恢复内存原始配置，不留磁盘修改痕迹。  
  
> 🚨攻击手段极具隐蔽性：  
> 攻击者不植入 WebShell、不留下持久化后门，全部命令直接通过 HTTPS 攻击通道下发，结果在 HTTP 响应中回传；主动清理 VPN 调试日志、Linux 审计日志；仅在内存做改动，Ivanti 官方完整性校验工具 Integrity Checker 无法发现入侵痕迹；仅靠杀毒扫描、文件巡检，完全无法排查入侵。  
  
## 入侵之后：目标直指企业域控核心数据  
  
拿到 VPN 设备 root 权限后，攻击者以 VPN 设备的 AD 域服务账号身份，通过 LDAP 协议查询域控制器，疯狂搜刮企业核心机密： ✅ LAPS 本地管理员密码 ✅ BitLocker 磁盘恢复密钥 ✅ 域账户密码相关字段、登录脚本路径、用户信息 ✅ 抓取网络流量，窃听 LDAP、HTTP 基础认证、NTLM 哈希凭据 ✅ 本地提取 VPN 设备保存的各类凭证，梳理有效账号，执行密码喷洒攻击 ✅ 内网网络探测，导出窃取的数据，为横向移动做准备。  
  
Volexity 研判，该攻击和此前 SonicWall VPN 凭证窃取活动思路高度相似：**瞄准边界 VPN 网关作为突破口，一旦边界失守，整个内网 AD 域面临沦陷风险**  
，但两次攻击并非同一威胁团伙所为。
