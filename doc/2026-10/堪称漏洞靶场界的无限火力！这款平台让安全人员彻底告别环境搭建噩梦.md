重点导读概述
Vulfocus 是一款基于 Docker 的漏洞集成平台，支持一键启动漏洞环境。该平台采用前后端分离架构，后端基于 Django 框架构建 API 服务，前端使用 Vue.js 构建用户界面，Redis 作为缓存队列，Celery 处理异步任务。
核心设计理念围绕漏洞环境的快速交付与循环利用展开。每个漏洞以 Docker 镜像形式存在，启动后自动生成 Flag 并写入指定目录，用户提交正确 Flag 后环境自动销毁并还原。这一机制确保了环境的不可破坏性与无限次复用特性。
重点导读核心特性
PART 01一键启动
用户无需手动配置任何依赖环境。平台整合了 Vulhub 和 Vulapps 两大主流漏洞环境仓库的全部镜像资源，覆盖 Web 安全、数据库、中间件等多个漏洞类别。通过简单的镜像拉取与启动操作，即可立即获得可用的漏洞测试环境。
PART 02Flag 机制
平台内置自动化 Flag 生成与验证系统。每次启动漏洞环境时，系统自动向目标容器写入随机生成的 Flag 值，用户通过漏洞利用获取 Flag 后提交，系统实时验证答案正确性，验证通过后自动关闭环境。这一机制有效防止了环境破坏导致的服务不可用问题。
PART 03计分考核
平台提供完善的计分功能，支持安全人员技能考核场景。管理员可为每个漏洞镜像设置分值，普通用户启动镜像、提交 Flag 后获得相应积分。该功能已广泛应用于企业内部安全培训与高校网络安全课程的能力评估环节。
PART 04可视化编排
支持图形化方式编排多容器漏洞场景。用户可通过拖拽操作组合多个漏洞镜像，构建复杂的攻防对抗环境。场景模式允许普通用户权限操作，降低了高级漏洞环境的使用门槛。
重点导读技术架构
PART 05前端技术栈
前端基于 Vue.js 框架构建，采用 Element UI 组件库实现界面开发。项目配置了多环境支持，包括开发环境、生产环境与预发布环境。通过 Vue CLI 进行构建管理，支持按需加载与代码分割优化。
PART 06后端技术栈
后端采用 Django 框架开发 RESTful API 服务。Django ORM 负责数据库操作，SQLite 作为默认数据库存储用户信息、漏洞镜像元数据与考核记录。Redis 提供缓存与消息队列功能，Celery 异步 worker 负责镜像拉取、启动、停止等耗时操作的 background 处理。
PART 07容器编排
平台核心依赖 Docker 容器技术实现漏洞环境隔离。通过挂载宿主机的 Docker Socket 实现容器管理能力，支持动态创建、启动、停止与销毁漏洞容器。网络层面采用 Docker Bridge 模式确保漏洞环境与宿主机网络隔离，同时提供端口映射机制将容器内服务暴露给用户访问。
重点导读部署方式
PART 08Docker Compose 部署
项目提供完整的 Docker Compose 编排配置，涵盖 Redis 缓存服务、Django API 服务、Celery Worker 服务与 Nginx 前端服务四个核心组件。一键启动命令即可完成全部服务的部署与配置。
docker create -p 80:80 -v /var/run/docker.sock:/var/run/docker.sock -v /xxx/db.sqlite3:/vulfocus-api/db.sqlite3 -e VUL_IP=xxx.xxx.xxx.xxx vulfocus/vulfocus:latest

PART 09自行搭建
对于自行搭建场景，项目提供 INSTALL.md 详细文档说明依赖安装与数据库初始化流程。核心依赖包括 Python 3、Docker、Redis 与 Nginx。部署时需注意首次启动前导入最新数据库文件以避免版本不兼容问题。
重点导读镜像管理
PART 10镜像拉取
平台官方 Docker Hub 仓库地址为 https://hub.docker.com/u/vulfocus。管理员可在镜像管理界面通过输入镜像名称直接拉取官方仓库镜像。镜像支持文本拉取与文件上传两种模式，文件模式允许导入本地打包的 tar 镜像文件。
PART 11镜像同步
平台提供一键同步功能，可将官方仓库中的新增漏洞镜像批量同步至本地。同步过程中会跳过已存在的镜像版本，避免重复下载。网络配置部分需将同步源地址由 vulfocus.fofa.so 替换为 vulfocus.cn 以确保链路可用。
重点导读场景编排
PART 12场景构建
场景模式支持通过压缩包方式批量构建漏洞环境。管理员在环境编排管理界面选择创建编排模式，上传预制的场景压缩包文件。平台自动解析压缩包内容并下载所需的 Docker 镜像资源，发布成功后即可供普通用户使用。
PART 13计时模式
平台内置镜像运行时长控制功能。管理员可在系统配置页面设置单个镜像或全局的运行时长限制。镜像启动后自动开始计时，超时后系统强制关闭容器。该功能适用于考核场景下的公平性保障。
重点导读典型应用场景
PART 14企业安全培训
企业安全团队可利用 Vulfocus 构建定制化的漏洞学习环境，针对业务系统常见漏洞类型进行专题培训。计分功能支持生成培训效果评估报告，为后续培训计划提供数据支撑。
PART 15CTF 比赛
平台支持构建多漏洞串联的复杂场景，适用于 CTF 竞赛环境搭建。Flag 机制确保比赛公平性，计时模式满足竞速类题目需求，可视化编排大幅降低复杂场景的搭建成本。
PART 16日常渗透测试
渗透测试工程师在测试目标系统时，可通过平台快速启动相关漏洞环境进行本地复现与分析。Docker 镜像的隔离特性保证了测试过程不会影响生产环境，环境销毁后即可还原至初始状态。
