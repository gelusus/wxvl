**以下漏洞需特别注意**  
  
  
  
  
Windows Shell 安全功能绕过漏洞CVE-2026-96951  
  
严重级别：高危 CVSS:8.8  
  
被利用级别：检测到利用  
  
  
此漏洞需要用户交互。该漏洞源于Windows Shell对命令中特殊元素的处理不当，存在命令注入缺陷，攻击者可利用该缺陷绕过Windows对互联网来源文件的部分安全检查，绕过网络来源标记相关的安全防护。触发该漏洞需要诱导用户与攻击者控制的内容交互，例如通过电子邮件或即时消息诱导用户打开特制文件，或点击指向攻击者网站的链接。成功利用后，攻击者可能绕过Windows的Mark of the Web（MOTW，网络来源标记）安全防护机制。  
  
  
Microsoft QUIC 远程代码执行漏洞CVE-2026-100219  
  
严重级别：严重 CVSS:9.8  
  
被利用级别：有可能被利用  
  
  
此漏洞不需要用户交互。该漏洞源于Microsoft QUIC组件在处理网络通信数据时继续访问已经释放的内存，导致程序访问无效内存，该内存访问缺陷可能被进一步利用，使攻击者在受影响系统上执行任意代码。触发该漏洞无需攻击者提供身份验证凭据，但要求目标系统存在使用受影响QUIC组件的网络服务，且攻击者能够通过网络访问该服务。成功利用后，攻击者可能在受影响系统上远程执行任意代码。  
  
  
Windows 消息队列管理器远程代码执行漏洞CVE-2026-100202  
  
严重级别：严重 CVSS:9.8  
  
被利用级别：有可能被利用  
  
  
此漏洞不需要用户交互。该漏洞源于Windows消息队列管理器在处理网络消息时继续访问已经释放的内存，该缺陷可能被攻击者利用，使受影响的服务执行任意代码。触发该漏洞无需攻击者具备身份验证凭据，但要求目标系统已启用Windows消息队列服务，且攻击者能够通过网络向该服务发送特制消息。成功利用后，攻击者可能在受影响系统上远程执行任意代码。  
  
  
Windows 搜索组件特权提升漏洞CVE-2026-105010  
  
严重级别：严重 CVSS:9.8  
  
被利用级别：有可能被利用  
  
  
此漏洞不需要用户交互。该漏洞源于Windows搜索组件在运行过程中继续访问已经释放的内存，导致程序访问无效内存，该内存访问缺陷可能被进一步利用，使攻击者突破原有的权限限制。攻击者无需身份验证，即可通过网络向受影响的服务发送特制数据包触发该漏洞，成功利用后，攻击者可能将其权限提升至SYSTEM。  
  
  
Windows DHCP 服务器远程代码执行漏洞CVE-2026-96934  
  
严重级别：严重 CVSS:9.8  
  
被利用级别：有可能被利用  
  
此漏洞不需要用户交互。该漏洞源于Windows DHCP配置协议服务器中，程序继续访问已经释放的内存，导致相关内存数据可能遭到破坏，攻击者可能利用该缺陷执行恶意代码。触发该漏洞要求目标系统运行受影响的服务，且攻击者能够通过网络向该服务发送特制数据包，成功利用后，攻击者可能在受影响系统上远程执行任意代码。
