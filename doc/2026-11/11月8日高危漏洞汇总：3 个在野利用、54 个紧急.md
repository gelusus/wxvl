## 01  本期概览  
  
11 月 1 日到 8 日，内容池里 112 条高分条目，CVSS 9.0 以上的 **54 条**  
，进 KEV 在野利用目录的 **3 条**  
。数字比上周热闹，热闹和优先级是两件事：这 54 个里大半需要凭据、或者厂商早就修好了、或者干脆没人维护。  
  
这周最该修的一个洞点名：**CVE-2026-19868**  
，SonicWall SSLVPN。它分数只有 7.5，不是最亮眼的那个，但它拆的是很多人以为已经建好的那道门，MFA。  
  
## 02  在野利用，先修这个  
  
本周三个进入 KEV 的漏洞，过去几天都单独写过详解，这里只留结论和动作。  
  
CVE-2026-19868  
7.5 在野  
  
SonicWall SonicOS SSLVPN 认证强制缺陷。SAML 开着，但本地用户、LDAP、RADIUS 账号还能登 VPN 时，这些账号的密码直接绕过 SAML 和它强制的 MFA，建立 VPN 会话进内网。  
  
影响 Gen7 7.3.3-7015 及更早、Gen8 8.2.2-8015 及更早；修到 Gen7 7.3.4-7013、Gen8 8.2.3-8015，无临时缓解  
  
CVE-2024-27834  
5.5 在野  
  
Apple 多产品的认证校验缺陷，被 APT29 串成零点击利用链打 iOS 和 macOS。分数不高，打的是不常升级的那批设备。  
  
影响 iOS/iPadOS 17.5 之前、16.x 的 16.7.8 之前、macOS 14.5 之前；修到 iOS 17.5 与 16.7.8、macOS 14.5  
  
CVE-2026-119977  
8.1 在野  
  
WordPress Core 的升级窗口竞态。全量包升级时文件先解到可预测目录，抢在搬运前调用暂存安装器写入 wp-config.php，未认证即可执行代码。  
  
影响 4.7.0 到 7.1.3；修在 7.1.4 及各分支最小修复版本  
  
## 03  9 分以上，本周这一批  
  
CVE-2026-109469  
10.0 已缓解  
  
分数本周最高，但你不需要做任何事。Entra 设备注册的授权绕过，未认证远程提权，云端已全量缓解，公开前没有被利用。列在这里是因为它说明一种情况：云服务的 10 分洞，可以没有补丁动作。  
  
CWE-639 用户可控键；影响 Microsoft Entra 云服务，无需本地处置  
  
IBM API Connect 一批  
最高 9.9  
  
授权绕过、任意文档修改、敏感信息读取、管理员操作越权。API 网关是横向移动的枢纽，凭据泄露之后它就是下一个目标。  
  
本周 9 分以上 7 个；影响 10.0.8.0–10.0.8.12、12.1.0.0–12.1.1.2；修到 12.1.1.3  
  
Kyverno 一批  
9.9 提权  
  
命名空间管理员能逃出命名空间限制：清理控制器用空策略建上下文、apiCall 的 urlPath 未校验、签名校验可绕过，一路走到集群权限。  
  
影响 1.17.0 到 1.19.1，共 6 个 CVE；修到 1.19.2  
  
LXD / Incus 一组  
9.9 宿主 root  
  
恶意镜像服务器返回伪造的   
Incus-Image-Hash  
 头，路径穿越把内容写到任意位置，例如 cron 目录，随即在宿主机上以 root 执行。另一条是实例快照绕过   
restricted.containers.lowlevel=block  
，用低级钩子执行命令。  
  
5 条公告：9.9 两条、7.7 两条（跨项目拷贝绕过）、5.0 一条（镜像导入 SSRF）；Incus 修在 7.2.0，LXD 同步  
  
CVE-2026-123218  
9.8 管理员  
  
IBM Aspera Faspex：已认证用户构造一条特制消息就能绕过授权，拿到完整管理员权限。  
  
影响 5.0.0 到 5.0.19；修在 5.0.19 PL1，无临时缓解  
  
路由器固件一批  
10.0 未修  
  
奇虎 360 家庭路由 M5 与 D6xx/D706（启动脚本硬编码凭据、固件签名校验失效）、Linksys E5350（安装向导缺认证，可改管理密码）、TOTOLINK A950RG（Easy Setup 栈溢出）、Comfast CF-WR632AX（multipart 文件名路径穿越）。PoC 全部公开，四家厂商都没回应。  
  
补丁基本不会来；处置只有把管理面撤出公网，到期换设备

## 05  修复优先级  
  
**1.**  
 今晚：SonicWall SSLVPN。先确认还有没有非 SAML 账号能登 VPN，有就今晚升。  
  
**2.**  
 今晚：跑 Kyverno 的集群。命名空间管理员拿到集群权限，多租户隔离等于失效。  
  
**3.**  
 三天内：LXD/Incus 宿主。前提是攻击者能创建实例或镜像，但一旦写进 cron 目录就是 root。  
  
**4.**  
 一周内：IBM API Connect 升到 12.1.1.3，Aspera 升到 5.0.19 PL1。  
  
**5.**  
 常规节奏：Chrome 升 157；Entra 不用动；家用路由器升不了，就改配置或换机。  
  
三条自查命令：  
  
kubectl get cleanuppolicy -A  
  
snap list lxd  
   # 或 incus version  
  
apic --version  
  
第一条列出所有命名空间策略，配合版本看是否还在 1.19.1 及以下；第二、三条确认容器与 API 网关版本。  
  
## 06  一句判断  
  
54 个 9 分洞里，大半是要凭据才能打、或者厂商早修好的。分高不等于急，能拆掉你已有防线的那一个才急。SonicWall 拆的是 MFA，Kyverno 拆的是命名空间，LXD 拆的是宿主机隔离，这三样恰好都是很多人画架构图时以为已经解决了的问题。  
  
还有一个变化值得记一下：公开 PoC、厂商不回应、漏洞永远停在固件里，正在变成家用和中小企业设备的常态。这些设备不会出现在资产台账上，但它们和你的内网在同一张网里。
