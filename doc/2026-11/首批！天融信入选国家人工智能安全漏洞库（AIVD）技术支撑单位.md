#  首批！天融信入选国家人工智能安全漏洞库（AIVD）技术支撑单位  
 天融信   2026-11-16 04:02  
  
![](https://mmbiz.qpic.cn/mmbiz_gif/nJmicCz2NYxNibMqIOfXMnZxbVBPBGKu3pficMjqFslyVdhUYhSozJ0egjyKoezIaK9qEyYy6ttzMv3T5Kiasiae7icg/640?wx_fmt=gif&from=appmsg&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=0 "")  
  
  
**AIVD首批支撑单位**  
  
  
近日，中国信息安全测评中心正式公布国家人工智能安全漏洞库（AIVD）技术支撑单位名单，天融信依托长期在国家级漏洞挖掘、研判验证、应急处置以及AI安全测评领域的技术积淀成功入选，成为首批支撑单位。  
  
  
![](https://mmbiz.qpic.cn/mmbiz_jpg/dSWSuPicfjTd17MHk93KGp0q4bcAt0e11Vf54aoz0K1jTEN5cPHGQyY6n0TAaiayicu2IeYZ3scCazwm9ullUnKcM6WOXThCDyPfWLo0QbWmWc/640?wx_fmt=jpeg&from=appmsg "")  
  
  
  
  
国家人工智能安全漏洞库由国家信息安全漏洞库（CNNVD）于2026年4月启动运行，由中国信息安全测评中心负责相关管理，专门面向人工智能系统与应用的漏洞开展收集、研判、通报与治理，是CNNVD在人工智能领域的延伸。平台聚焦大模型、智能系统、AI应用及其框架、平台与供应链组件，着力构建人工智能漏洞“发现—归集—研判—通报—处置”的协同治理链条。  
  
  
**国家级漏洞库支撑积淀深厚**  
  
  
**技术能力覆盖AI应用全生命周期**  
  
  
入选首批AIVD支撑单位，并非偶然。天融信是  
CNNVD、  
CNVD、NVDB等国家级漏洞库支撑单位，长期承担国家级漏洞的发现、报送、验证与应急支撑工作，原创漏洞发现在企业排名中长期位居前列。  
  
  
在2026年度国家信息安全漏洞库（CNNVD）年度核心技术支撑单位能力评定与认定工作中，天融信获评“核心技术支撑单位”，并且在（第一期）CNNVD漏洞奖励评选中获“一级贡献奖”。除此之外，天融信已连续13年获评“国家信息安全漏洞库（CNNVD）技术支撑单位（一级）”。

面向新兴的人工智能安全赛道，天融信同样成果丰硕，此前已获评人工智能安全漏洞治理联盟首批成员单位、首批国家人工智能安全漏洞库优秀技术支撑单位等多项荣誉，  
在AI安全技术创新与漏洞挖掘方面持续积累，扎实实践。  
  
  
依托自研AI安全评估系统及渗透测试、漏洞扫描等检测手段，天融信在真实AI资产上沉淀检测与验证能力，为AIVD漏洞研判、样本复现与影响评估提供实战底座。  
  
  
天融信打造的AI漏洞挖掘智能体具备自主任务分解与多步推理能力，可针对开源框架、闭源商业软件自动完成从目标测绘、攻击面枚举、漏洞挖掘到PoC生成与验证的全流程操作。  
  
  
天融信AI安全运营中心可推动漏洞从线索发现到处置建议输出形成闭环，为AIVD支撑提供常态化运营保障。  
  
  
![](https://mmbiz.qpic.cn/mmbiz_png/dSWSuPicfjTcBsARkIhF15IQ5E3E1mF7Zb7qkRFiaedU5foUg08tNX89VwUUHbDX8GaYfDs9Uy9CQhZsF20aJBwbXiacJ9yWBY9jYgtdx77HS4/640?wx_fmt=png&from=appmsg "")  
  
  
以此次入选首批支撑单位为起点，天融信将配合AIVD做好AI漏洞线索报送、技术研判与协同处置，协同提升国内人工智能安全韧性。未来，天融信将坚持安全与智算并进，依托成熟技术、产品、方案与服务能力，助力全行业客户提升智能化安全防御水平。
