#  【已复现】LibreOffice 打开恶意文档即可触发远程代码执行  
原创 360漏洞研究院
                    360漏洞研究院  360漏洞研究院   2026-11-17 06:48  
  
LibreOffice 披露两项高危远程代码执行漏洞（CVE-2026-104007、CVE-2026-104692，CVSS 8.5）。攻击者可通过构造特制电子表格及其关联数据库配置，诱导用户打开恶意文档，使存在漏洞的客户端加载并执行不可信 Java 代码，最终以当前用户权限执行任意系统命令。  
  
  
**利用前置条件：**  
- 目标用户使用 LibreOffice 打开特制文档  
  
- 已安装 Java 运行环境，LibreOffice 中已启用 Java 功能  
  
**目前图龙锋已成功复现该漏洞。**  
本文包含完整影响范围、正式修复方案、技术原理与复现细节。

**01**  
  
**漏洞影响范围**  
  
  
  
受影响的软件版本：  
  
LibreOffice 26.2 分支：26.2 <= 受影响版本 <  26.2.7  
  
LibreOffice 26.8 分支：26.8 <= 受影响版本 < 26.8.2  
  
  
**02**  
  
**修复建议**  
  
  
  
**正式防护方案**  
  
LibreOffice 26.2 分支：升级至 >= 26.2.7  
  
LibreOffice 26.8 分支：升级至 >= 26.8.2  
  
  
**03**  
  
**漏洞描述**  
  
  
  
近日，LibreOffice 官方披露了两项高危远程代码执行漏洞（CVE-2026-104007、CVE-2026-104692）。其中，CVE-2026-104007 源于 JDBC 驱动加载路径受不可信数据库文档控制，攻击者可通过特制文档指定恶意 Java 类加载路径；CVE-2026-104692 则源于 HSQLDB 在通过通用 JDBC 驱动访问时未正确执行 Java 方法调用限制，导致非预期 Java 方法能够被调用。攻击者可结合电子表格中的外部数据源引用及表单自动加载机制，诱导用户打开特制 ODS 文档，在无需启用宏的情况下触发恶意代码执行，最终以当前用户权限执行任意系统命令，对终端系统安全构成严重威胁。  
  
  
**04**  
  
**漏洞复现**  
  
  
  
360漏洞研究院依托图龙锋已成功复现 CVE-2026-104007、CVE-2026-104692。打开特制 ODS 文档触发外部数据库加载并成功启动计算器程序，验证了任意代码执行风险。
