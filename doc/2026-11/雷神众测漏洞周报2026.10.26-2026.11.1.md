**1.Vite和Vite-plus任意文件读取漏洞**  
  
  
漏洞介绍：  
  
Vite是一款新一代前端构建工具。Vite-plus是一个统一的前端开发工具链。  
  
  
漏洞危害：  
  
Vite存在任意文件读取漏洞，该漏洞源于开发服务器的WebSocket连接未能正确验证Origin头，攻击者可利用该漏洞通过vite:invoke事件调用fetchModule函数，结合file://协议和特定查询参数，以JavaScript字符串形式读取服务器上的任意文件。  
  
  
漏洞编号：  
  
CVE-2026-39363  
  
  
影响范围：  
  
Vite Vite >=8.0.0, <8.0.5  
  
Vite Vite >=7.0.0, <7.3.2  
  
Vite Vite >=6.0.0, <6.4.2  
  
Vite vite-plus <0.1.16  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本  
  
  
来源：  
CNVD  
  
**2.Laravel Livewire代码注入漏洞**  
  
  
漏洞介绍：  
  
Laravel Livewire是Laravel的一个全栈框架，让你用纯PHP就能构建动态、响应式的前端界面，无需写JavaScript代码。  
  
  
漏洞危害：  
  
Laravel Livewire存在代码注入漏洞，该漏洞源于组件属性更新处理不当，攻击者可利用该漏洞导致远程命令执行。  
  
  
漏洞编号：  
  
CVE-2025-54068  
  
  
影响范围：  
  
Laravel Livewire >=3.0.0-beta.1, <3.6.4  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本  
  
  
来源：  
CNVD  
  
  
**3.Ivanti Endpoint Manager Mobile操作系统命令注入漏洞**  
  
  
漏洞介绍：  
  
Ivanti Endpoint Manager Mobile是Ivanti公司推出的企业级移动设备管理（MDM）解决方案‌。  
  
  
漏洞危害：  
  
Ivanti Endpoint Manager Mobile存在操作系统命令注入漏洞，该漏洞源于未能正确验证用户输入，攻击者可利用该漏洞以root身份执行任意命令。  
  
  
漏洞编号：  
  
CVE-2026-10727  
  
  
影响范围：  
  
Ivanti Endpoint Manager Mobile <12.7.0.2  
  
Ivanti Endpoint Manager Mobile <12.9.0.1  
  
Ivanti Endpoint Manager Mobile <12.8.0.3  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本  
  
  
来源：  
CNVD  
  
**4.Ivanti Sentry授权问题漏洞**  
  
  
漏洞介绍：  
  
Ivanti Sentry是Ivanti公司的一款安全网关产品‌。

漏洞编号：  
  
CVE-2026-83527

Ivanti Sentry <R10.8.2  
  
Ivanti Sentry <R10.7.3  
  
Ivanti Sentry <R10.6.4  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本
