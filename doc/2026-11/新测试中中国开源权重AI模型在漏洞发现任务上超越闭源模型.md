#  新测试中中国开源权重AI模型在漏洞发现任务上超越闭源模型  
爱拍照的老李
                    爱拍照的老李  爱拍照的老李   2026-11-26 01:00  
  
**导****读**  
  
  
  
在一项新的网络安全测试中，中国人工智能企业推出的两款开源权重大型语言模型（LLMs）表现优于美国同行的闭源模型。  
  
  
以色列人工智能网络安全公司A Security对中国企业开发的大语言模型DeepSeek V4.1 Flash以及GLM 5.3，与谷歌、xAI和OpenAI的五款商用人工智能模型进行了性能测试。  
  
  
该测试基于A Security在ARENA上构建的一个基准测试平台，ARENA是一个开源生成器，可创建包含已植入且经验证的漏洞以及Web应用防火墙、速率限制和隐藏端点等真实防护机制的容器化Web应用程序。  
  
  
该研究评估了不同AI模型作为A Security四智能体渗透系统引擎的表现，各模型均在包含14个漏洞的中型实验室环境中处理相同的100条潜在线索，且每个模型都进行了三次测试运行。  
  
  
由于这些实验环境是专门为本次测试搭建的，没有任何模型能在这些环境上进行过训练。  
  
  
DeepSeek 与 GLM 性能优于 Gemini、Grok 及 GPT 系列模型  
  
  
两款中文模型均与所有参与测试的模型持平或表现更优，其中 DeepSeek V4.1 Flash 每次运行都能识别出 93% 已验证的漏洞，在所有模型中识别率最高。  
  
  
与此同时，GLM 5.3 每次运行能发现86%的漏洞，并且是三款模型中唯一一款在三次运行中至少找出所有漏洞的模型。闭源模型的表现均较差。Gemini 3.8 Flash 排名第三，每次运行也能发现86%的漏洞，但它在三次运行中从未达到100%的检出率，最高仅为93%。

DeepSeek V4.1 每次运行都得出了93%的相同结果，而 GLM 5.3 在三次运行中至少发现了一次所有漏洞。来源：A Security  
  
  
此外，A Security 发现 DeepSeek V4.1 Flash 的成本仅为其他模型的零头，每份经过验证的结果费用为0.81美元，而闭源模型的费用在9.54美元（Gemini 3.8 Flash）至31.85美元（GPT 5.6 Sol）之间。  
  
  
GLM 5.3 的成本效益并不高，每一项经过验证的结果成本为10.49美元，略高于最便宜的闭源模型。  
  
  
研究局限性：成本范围与供应商变量使结果复杂化  
  
  
尽管A安全测试是另一个体现中国开源权重人工智能模型受关注度不断提升的例子，但11月23日发布的这项研究结果，并不意味着这些模型在发现漏洞方面始终更出色或成本更低。  
  
  
此外，这家以色列公司明确表示，成本数据仅涵盖四名开发代理，不包括发现、浏览器使用、报告、顾问通话及其他编排成本，部分原因是不同运行批次的顾问配置存在差异。完整扫描的成本会更高，且成本会因配置设置而有所不同。  
  
  
定价基础也有所不同：GLM 5.3 按其官方令牌费率定价，而其他模型则采用记录的供应商支出。DeepSeek 在之前通过另一家供应商的运行出现大量回退后，采用了固定的供应商路由，且运行时间反映了所使用的特定推理供应商和配置，因此不应将其视为固定的模型级速度排名。  
  
  
DeepSeek 的偏离程度也最大，在至少 4.5% 的目标线索中报告了超出其指定主导范围的发现结果，而其他模型的这一比例均低于 2.5%。尽管安全研究人员指出，此类考量对攻击者几乎没有影响，但这给防御方带来了范围控制方面的隐患，因为一个偏离其主导范围的智能体可能会接触到测试活动授权范围之外的资产。
