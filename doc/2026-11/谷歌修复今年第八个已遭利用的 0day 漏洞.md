#  谷歌修复今年第八个已遭利用的 0day 漏洞

**周一谷歌发布更新，修复了九个安全漏洞，其中包括一个已遭在野活跃利用的高危漏洞（CVE-2026-125350）。**  
  
该漏洞是XML组件中的一个释放后使用漏洞。释放后使用漏洞通常发生在程序试图访问一个已经被释放的内存位置时。成功利用这类漏洞可能使攻击者实现数据损坏、程序崩溃或任意代码执行。该漏洞由匿名安全研究员在2026年11月6日发现并报送。  
  
谷歌证实称“已知CVE-2026-125350的利用代码在野存在”，但未透露它在真实世界攻击中如何被滥用或幕后黑手身份等具体信息。谷歌提到， “在大多数用户更新修复之前，对漏洞详情和链接的访问可能会持续受限。如果该漏洞存在于其他项目同样依赖但尚未修复的第三方库中，我们也将保留限制状态。”  
  
这是迄今为止谷歌今年处理的第八个遭在野利用的Chrome 0day漏洞，其它还包括CVE-2026-2441、CVE-2026-3909、CVE-2026-3910、CVE-2026-5281、CVE-2026-11645、CVE-2026-85046和CVE-2026-87491。  
  
为获得最佳保护，建议用户将Chrome浏览器更新至157.0.8103.50/.51版本（Windows和Apple macOS），以及157.0.8103.50版本（Linux）。为确保安装最新更新，用户可导航至“更多”>“帮助”>“关于Google Chrome”，然后选择“重启”。建议使用其它基于Chromium的浏览器（如Microsoft Edge、Brave、Opera和Vivaldi）的用户，及时应用可用的修复方案。
