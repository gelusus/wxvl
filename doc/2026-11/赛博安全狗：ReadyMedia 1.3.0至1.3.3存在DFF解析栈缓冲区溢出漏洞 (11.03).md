NIST发布后量子密码迁移最终报告，高价值联邦系统2030年设期限  
  
美国国家标准与技术研究院（NIST）发布最终版《后量子密码标准过渡》报告，指出当前易受量子攻击的密码标准及其抗量子替代标准，并为联邦机构给出迁移时间表和活动指引。报告称，虽然具备破解能力的量子计算机尚未出现，但“先窃取、后解密”威胁使现有加密数据已面临风险，因此建议对高敏感数据优先迁移至密钥建立标准FIPS 203。报告还讨论了将传统加密与后量子密码结合的混合方案及其代价。根据相关行政命令和OMB备忘录M-26-15，高价值资产与高影响系统须在2030年12月31日前完成后量子密钥建立、2031年12月31日前完成数字签名迁移；易受量子攻击的公钥密码2030年后被弃用、2035年后被禁用，国家安全备忘录10设定的2035年联邦整体迁移目标保持不变。

研究论文系统分析Google A2A协议 确认11项安全问题  
  
ACSAC 2026录用的论文《A2ABreak: Systematic Security Analysis of the A2A Protocol》针对Google的智能体间通信协议A2A v1.0.0，在假设各方遵守MUST、落实SHOULD、开启MAY安全选项的严格威胁模型下，借助大语言模型将协议规范转化为状态机，系统分析协议层安全缺陷，并经人工复核确认11项问题。研究重点剖析跨客户端上下文注入、多跳身份丢失、未经证明的能力声明三个代表性问题，并介绍规范抽取、状态机构建和漏洞发现验证流程。研究指出逐跳认证不等于端到端委托证明，A2A仍缺少必要的安全机制。

ReadyMedia 1.3.0至1.3.3存在DFF解析栈缓冲区溢出漏洞  
  
CVE-2026-29508于2026年11月2日发布，涉及ReadyMedia（前身为MiniDLNA）1.3.0至1.3.3版本中的基于栈的缓冲区溢出漏洞。远程攻击者可通过构造带有超大PROP块大小值的恶意DFF音频文件破坏栈内存，该值未经校验即被用于分配变长栈数组并读入文件数据。攻击者可将构造的DFF文件放入ReadyMedia监控的目录，借助inotify触发自动解析，在未启用防护的构建上实现远程代码执行，或在启用栈保护的加固构建上造成拒绝服务。该漏洞严重程度评分为8.8，属高危。
