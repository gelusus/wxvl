**1.OpenJDK Java4Shell 远程代码执行漏洞**  
  
  
漏洞介绍：  
  
Java SE（Java 平台标准版）是 Oracle 提供的 Java 标准平台，为企业级应用的开发与运行提供运行时环境和核心类库，广泛部署于服务器端系统、中间件及大数据组件等场景。  
  
  
漏洞危害：  
  
在搭载 AVX-512 VBMI 指令集的 x86-64 平台上，JVM 的优化解码路径处理畸形 Base64 数据时，尾部填充的长度计算会发生下溢，生成错误的写入掩码并越界覆盖相邻堆对象。攻击者只需把恶意数据送进应用调用 Base64 解码的环节即可触发，可导致服务崩溃，在满足利用条件时造成敏感信息泄露以及远程代码执行。  
  
  
漏洞编号：  
  
CVE-2026-114938  
  
  
影响范围：  
  
Oracle Java SE  
  
• JDK 8：仅企业性能变体 8u511b33-perf 受影响（JDK 8 标准线不受影响）  
  
• JDK 17：17.0.6 至 17.0.21.0.3（17.0.5 及更早不受影响）  
  
• JDK 21：21 至 21.0.13.0.3  
  
• JDK 25：25 至 25.0.5.0.3  
  
• JDK 27：27 至 27.0.1.0.3  
  
Oracle GraalVM for JDK  
  
• JDK 17：17.0.6 至 17.0.21.0.3  
  
• JDK 21：21 至 21.0.13.0.3  
  
Oracle GraalVM Enterprise Edition  
  
• 21.3 线：21.3.20.0.3（更早 EOL 版本以 Oracle 清单为准）  
  
OpenJDK 各发行版  
  
• 涵盖 Temurin、Corretto、Microsoft Build of OpenJDK、Zulu、Liberica、SapMachine、Red Hat OpenJDK 等  
  
• JDK 17/21/25/27：对应上述版本区间亦受影响  
  
• 硬件限制：仅限支持 AVX-512 VBMI 的 x86-64 平台（Intel Ice Lake 及更新、AMD Zen 4 及更新），ARM64 不受影响  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本

**2.Nginx多个远程代码执行漏洞（NGINX2Root）**  
  
  
漏洞介绍：  
  
Nginx 是一款高性能的 HTTP 服务器与反向代理，支持负载均衡、缓存加速、TLS 卸载与动态模块扩展，并内置 IMAP/POP3/SMTP 邮件代理；采用事件驱动的异步架构，以高并发、低资源占用著称，是全球部署量最大的 Web 服务器之一，广泛用作网站入口、CDN 和 API 网关。  
  
  
漏洞危害：  
  
均无需认证即可远程触发，成功利用可造成远程代码执行，串联Linux内核SCTP释放后使用漏洞还可提权至宿主机root并逃逸Docker容器。  
  
  
漏洞编号：  
  
CVE-2026-123007/123634/123633/121810/113425  
  
  
影响范围：  
  
CVE-2026-123007：Nginx Open Source 1.9.5 - 1.31.8；Nginx Plus 37.0.0 - 37.0.7.1、37.1.0 - 37.2.0.1、R34 - R36  
  
CVE-2026-123633：Nginx Open Source 1.19.7 - 1.31.8；Nginx Plus 37.0.0 - 37.0.6.x、37.1.0 - 37.2.0.1、R34 - R36  
  
CVE-2026-123634：Nginx Open Source 0.6.18 - 1.31.8；Nginx Plus 37.0.0 - 37.0.7.1、37.1.0 - 37.2.0.1、R34 - R36  
  
CVE-2026-121810：Nginx Open Source 1.25.0 - 1.31.8；Nginx Plus 37.0.0 - 37.0.7.1、37.1.0 - 37.2.0.1、R34 - R36  
  
CVE-2026-113425：Nginx Open Source 0.5.33 - 1.31.8；Nginx Plus 37.0.0 - 37.0.7.1、37.1.0 - 37.2.0.1、R34 - R36  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本

**3.PHP远程代码执行漏洞（phpAfterShell）**  
  
  
漏洞介绍：  
  
PHP（Hypertext Preprocessor）是一种广泛使用的开源服务器端脚本语言，主要用于 Web 开发领域，可快速构建动态网站与 Web 应用；全球大量内容管理系统、电商平台与企业业务系统均基于 PHP 运行。  
  
  
漏洞危害：  
  
该漏洞源于 PHP 默认 files 会话处理器在写入会话文件前未先清空原文件，写入被中断后会话文件会残留「新会话前缀 + 旧会话后缀」的混合内容，后续会话初始化可将其反序列化为对象，在存在可用 gadget 链的应用中实现远程代码执行。  
  
  
漏洞编号：  
  
CVE-2026-126714  
  
  
影响范围：  
  
PHP 8.2.0 至 8.2.35、8.3.0 至 8.3.36、8.4.0 至 8.4.27、8.5.0 至 8.5.12  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本  
  
**4.Microsoft Windows Error Reporting参数注入权限提升漏洞**  
  
  
漏洞介绍：  
  
Windows Error Reporting是Windows操作系统内置的系统反馈机制，当程序出现崩溃、无响应或内核错误时自动触发，用于收集错误类型、日志文件、内存快照及软件配置信息并提交至微软服务器以获取解决方案链接。  
  
  
漏洞危害：  
  
Microsoft Windows Error Reporting存在参数注入权限提升漏洞，该漏洞源于WER在处理Time Travel Debugging相关请求时，对Process参数的分隔符处理不当所致，攻击者可利用该漏洞进行本地提升权限。  
  
  
漏洞编号：  
  
CVE-2026-97798  
  
  
影响范围：  
  
Microsoft Windows Server 2022 >=10.0.20348.0，<10.0.20348.5761  
  
Microsoft Windows Server 2025 >=10.0.26100.0，<10.0.26100.33650  
  
Microsoft windows 10 21H2 >=10.0.19044.0，<10.0.19044.7807  
  
Microsoft Windows 10 22H2 >=10.0.19045.0，<10.0.19045.7807  
  
Microsoft Windows 11 23H2 >=10.0.22631.0，<10.0.22631.7652  
  
Microsoft Windows 11 24H2 >=10.0.26100.0，<10.0.26100.9711
