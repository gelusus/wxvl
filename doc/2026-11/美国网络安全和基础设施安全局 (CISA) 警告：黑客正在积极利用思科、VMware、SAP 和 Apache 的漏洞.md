#  美国网络安全和基础设施安全局 (CISA) 警告：黑客正在积极利用思科、VMware、SAP 和 Apache 的漏洞  
原创 ZM
                    ZM  暗镜   2026-11-27 22:00  
  
2026 年 11 月 20 日，美国网络安全和基础设施安全局 (CISA) 将影响 Cisco Expressway、VMware vCenter、SAP NetWeaver 和 Apache Roller 的四个漏洞添加到其已知利用漏洞 (KEV) 目录中。该机构列举了所有四个漏洞均已被积极利用的证据。CISA的警报并未指明受害者身份，也未将这些漏洞与任何单一攻击活动联系起来。Cisco 的CVE-2026-76466是一个硬编码凭证漏洞，CVSS 评分为 9.8。它会影响易受攻击的 Expressway Core 和 Expressway Edge 设备以及在集群中配置的虚拟部署。  
  
成功利用此漏洞可使未经身份验证的远程攻击者以 root 身份执行操作系统命令。正如之前的Cisco Expressway 补丁报道中所述，Cisco 发布了 X15.5.20 来解决此问题，并建议运行 X14 或更早版本系统的客户迁移到已修复的版本。Cisco 没有提供任何替代方案。  
  
VMware vCenter 的 CVE-2026-123890 是 VMware Directory Service 中的一个严重级别身份验证绕过漏洞，严重性评分为 9.8。攻击者如果能够通过网络访问受影响的 vCenter 实例，就可以绕过身份验证并获得未经授权的管理权限。  
  
虽然这两起事件各不相同，但都说明了为什么防御者应该审查对虚拟化管理层的访问权限：单个 vCenter 实例可以管理多个主机及其虚拟机。SAP NetWeaver 企业门户受 CVE-2025-42884 漏洞影响，该漏洞的 CVSS 评分为 6.5。  
  
此漏洞源于数据查询逻辑中特殊元素处理不当，影响 Java 命名和目录接口 (JNDI) 查找。未经身份验证的攻击者可能利用此漏洞读取或修改服务器信息。SAP 已在 SAP 安全说明 3660969 中解决了此问题。尽管严重性评分相对较低，但 CISA 建议防御者在确定补丁优先级时考虑此漏洞的利用可能性。  
  
Apache Roller 也存在漏洞，其 CVE-2026-129448 允许攻击者在 4.0.0 到 6.1.4 版本中执行未经身份验证的远程代码，因为该应用程序在验证请求者身份之前会处理不受信任的数据。6.1.5 版本中也存在类似的漏洞，漏洞编号为 CVE-2026-82384。  
  
管理员应升级到 Roller 6.1.6 或更高版本。仅通过管理界面禁用 XML-RPC 并不能保护旧版本；无法立即升级的组织应实施 Apache 的配置缓解措施并重启 Roller。
