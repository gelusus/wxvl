**🧠 漏洞原理 · CVE-2026-112346**  
  
公告原文（英文，未翻译，以免语义走样）：  
  
OpenHands Software Agent SDK before 1.52.0 contains an unauthenticated remote code execution vulnerability where the DockerWorkspace and Apptainer workspace launchers bind the sandbox agent server to all network interfaces (0.0.0.0) with an empty session_api_keys list, disabling authentication by default. Attackers who can reach the published container port can send unauthenticated HTTP and WebSocket requests to execute arbitrary shell commands as root in the sandbox, access the mounted workspace, and read plaintext secrets from the secrets store.  
  
公告未给出 CWE 归类，按 CVSS 指标可把利用路径推为（**属推导，非公告原文**  
）：  
  
① 攻击者从「网络（可远程）」位置触达该组件的相关功能  
  
② 在无需账号、无需用户交互下提交触发缺陷的输入  
  
③ 达成机密性完全受损的效果  
  
注意 CVSS 的权限前提是 无需账号，这决定了它是「未认证即可打」还是「先要有一个账号才能打」，自查时优先级完全不同。  
  
更完整的攻击路径与代码细节，请查阅文末官方参考链接。

**❓ 常见疑问 · CVE-2026-112346**  
  
**Q：不接公网是不是就不用管？**  
  
A：不是。评分里攻击途径判定为「网络（可远程）」，内网只减少了入口数量，不改变缺陷本身。真正能降档的是「同时满足」：不对不可信网络暴露 + 相关功能确实未被使用 + 有可核查的配置记录。三者缺一，仍建议按正常排期修复。  
  
**Q：有没有不改版本的绕法？**  
  
A：公告未提供可用 workaround（原话多为「请升级至修复版本」）。这种情况下可做的只有收敛暴露面、收紧账号权限、加强该接口日志这三类缓解动作，都不能替代升级。  
  
**Q：升到哪个版本才算修好？**  
  
A：升级至 1.52.0（含）以上——以厂商公告的版本边界为准，不要只看主版本号；同一主版本线的补丁版（如 x.y.z 的 z）往往就是修复点。  
  
**Q：怎么判断有没有已经被人用过？**  
  
A：以公告描述的功能入口为圆心检索访问日志；当前 EPSS 1.01%；未列入 KEV 只代表未公开确认在野利用，不代表没被尝试过。 结论存疑时，先固定证据再升级版本，避免把现场抹掉。  
  
**Q：需要账号才能打，那是不是管住账号就行？**
