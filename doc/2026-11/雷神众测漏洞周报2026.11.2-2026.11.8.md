**1.Linux Kernel IPv4 TCP 释放后重用漏洞**  
  
  
漏洞介绍：  
  
Linux 内核是绝大多数 Linux 发行版的底层核心，负责进程调度、内存管理与网络协议栈等基础能力。  
  
  
漏洞危害：  
  
该漏洞源于IPv4 TCP三次握手处理中的竞态条件，攻击者无需账号、无需用户交互、无需任何本地权限，仅从网络侧连接目标开放的IPv4 TCP端口即可触发，造成内核内存损坏、信息泄露（绕过KASLR）与拒绝服务，并可无条件打穿至远程代码执行。安恒信息已在默认配置的Linux 6.18.55受影响内核上完成EXP级远程利用验证，经IPv4 TCP竞态触发UAF后打通完整利用链，成功获取目标主机root权限，实现从无认证网络访问到root的远程接管。  
  
  
漏洞编号：  
  
CVE-2026-98432  
  
  
影响范围：  
  
Linux Kernel 5.10.* < 5.10.272  
  
Linux Kernel 5.15.* < 5.15.223  
  
Linux Kernel 6.1.* < 6.1.190  
  
Linux Kernel 6.6.* < 6.6.159  
  
Linux Kernel 6.12.* < 6.12.113  
  
Linux Kernel 6.18.* < 6.18.56  
  
Linux Kernel 7.2.* < 7.2.10  
  
Linux Kernel 7.3-rc < 7.3-rc7  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本  
  
  
来源：  
安恒信息CERT  
  
**2.OpenSSH/musl 密码认证绕过漏洞**  
  
  
漏洞介绍：  
  
OpenSSH 是广泛使用的开源 SSH 远程登录与加密传输服务组件。  
  
  
漏洞危害：  
  
该漏洞源于 musl libc 的 crypt() 在失败时返回 "*"，当 sshd 对密码字段为 "*" 的账户借用其他账户的真实盐值执行 crypt() 时，257–1024 字节的超长口令会使 crypt() 返回 "*" 并与影子条目比较相等，攻击者无需有效凭据即可通过 SSH 密码认证登录仅允许密钥登录或已锁定密码的账户，并可在 root 密码登录或 Alpine 默认 alpine 用户免密 doas 场景下直接获取 root 权限。  
  
  
漏洞编号：  
  
CVE-2026-123158  
  
  
影响范围：  
  
2016 年以来至 10.6p2 之前，运行于 musl libc 且未启用 PAM 的 OpenSSH sshd（Alpine、OpenWrt、Buildroot、Yocto 及 musl Docker 镜像）  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本  
  
  
来源：  
安恒信息CERT  
  
  
**3.Microsoft Windows Update Stack本地权限提升漏洞**  
  
  
漏洞介绍：  
  
Windows 11（简称Win11）是微软开发的桌面操作系统，2021年10月5日正式推送，为Windows 10的后续版本。Windows Server 2025是微软公司研发的服务器操作系统，于2024年11月1日正式发布，接替前代系统Windows Server 2022。Windows Server 2025 (Server Core installation)是一款不带本地图形用户界面（GUI）的精简版本，包含Windows Server的核心组件并支持所有服务器角色，专为“无头”部署设计，通过远程工具管理‌。  
  
  
漏洞危害：  
  
Microsoft Windows Update Stack存在本地权限提升漏洞，该漏洞源于Windows更新堆栈时，未对访问文件前的链接进行正确的解析所致，具有权限的攻击者可利用漏洞进行本地权限提升。  
  
  
漏洞编号：  
  
CVE-2026-81963  
  
  
影响范围：  
  
Microsoft Windows 11 Version 23H2 >=10.0.22631.0，<10.0.22631.7582  
  
Microsoft Windows 11 Version 24H2 >=10.0.26100.0，<10.0.26100.9445  
  
Microsoft Windows 11 Version 25H2 >=10.0.26200.0，<10.0.26200.9445  
  
Microsoft Windows 11 version 26H1 >=10.0.28000.0，<10.0.28000.2954  
  
Microsoft Windows Server 2025 >=10.0.26100.0，<10.0.26100.33438  
  
Microsoft Windows Server 2025 (Server Core installation) >=10.0.26100.0，<10.0.26100.33438  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本  
  
  
来源：  
CNVD  
  
**4.JetBrains TeamCity代码执行漏洞**  
  
  
漏洞介绍：  
  
JetBrains TeamCity是由JetBrains公司开发的持续集成（CI/CD）工具‌。  
  
  
漏洞危害：  
  
JetBrains TeamCity存在代码执行漏洞，该漏洞源于版本化设置中Kotlin领域特定语言的沙箱隔离机制存在缺陷，未能有效限制代码执行。目前没有详细的漏洞细节提供。  
  
  
漏洞编号：  
  
CVE-2026-100253  
  
  
影响范围：  
  
JetBrains TeamCity <2026.2  
  
JetBrains TeamCity <2026.1.4  
  
JetBrains TeamCity <2025.11.8  
  
  
修复方案：  
  
及时测试并升级到最新版本或升级版本  
  
  
来源：  
CNVD
