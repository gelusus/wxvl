#  工信部漏洞库：关于防范Node.js越界写入超危漏洞的风险提示  
 华盟信安   2026-11-12 02:30  
  
可被未经身份验证的攻击者利用，破坏进程内存，进而导致程序崩溃、进程内存信息泄露或远程代码执行。  
  
  
近日，工业和信息化部网络安全威胁和漏洞信息共享平台（  
NVDB  
）监测发现，  
Node.js  
存在越界写入超危漏洞，危害严重。  
  
Node.js  
是一个开源的  
JavaScript  
运行环境，广泛用于  
Web  
服务器构建及命令行工具编写。其内置的  
Brotli  
解码器存在越界写入漏洞，可被未经身份验证的攻击者利用，破坏进程内存，进而导致程序崩溃、进程内存信息泄露或远程代码执行。当前仍处于维护期内的受影响版本包括：  
22.x  
系列＜  
22.23.4  
、  
24.x  
系列＜  
24.22.1  
、  
26.x  
系列＜  
26.12.1  
。  
  
目前，  
Node.js  
项目团队已修复上述漏洞并发布安全公告（  
URL  
链接：  
https://nodejs.org/zh-cn/blog/vulnerability/october-2026-security-releases  
）。建议相关单位和用户立即开展全面排查，及时升级至最新安全版本，消除网络安全隐患。
