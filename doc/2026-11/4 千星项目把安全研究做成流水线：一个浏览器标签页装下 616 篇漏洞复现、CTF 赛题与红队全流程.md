PeiQi 文库是一个面向网络安全从业者的静态知识站点，源码托管于 GitHub，仓库内以 685 篇 Markdown 文档构成主体内容，覆盖漏洞研究、代码审计、CTF 夺旗、红蓝对抗与信息收集等方向。站点基于 VuePress 与 AntDocs 主题构建，全量编译产物随仓库一同分发，使用者既可在本地二次开发，也可直接将编译结果部署至自有服务器。
重点导读项目定位
面向安全从业者的公开资料库，解决两个具体问题：安全信息分散导致的检索成本，以及漏洞复现资料难以系统化沉淀的问题。内容按产品与漏洞类型双维度组织，同时保留 CTF 实战与红队作战流程两类经验型资料。
截至 2023 年 11 月，仓库累计获得 4122 个 Star、615 个 Fork，GitHub 主题标签包含 cve、0day、1day、redteam、vuln 等关键词，站点通过仓库根目录的 CNAME 文件绑定独立域名。

PART 11流水线
GitHub Actions 提供 build 与 publish 两条工作流，Node.js 16 环境，缓存 Yarn 依赖目录，构建阶段设定 NODE_OPTIONS=--max_old_space_size=8193 以应对大规模图片资源导致的内存峰值。提交信息包含 skip ci 时跳过构建。
重点导读使用建议

漏洞条目按产品名称与 CVE 编号双重检索，命中后先读网络测绘段落，再进入复现段落。
复现请求包可直接复制，命令执行类漏洞优先在本地 Docker 环境验证。
需要沉淀自有内容的团队，可直接复用仓库的目录约定与文章模板，形成内部知识库。
编译产物体积约 1.6 GB，建议内网或本地部署，公网部署时按需裁剪图片资源。
