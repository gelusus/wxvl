Juniper Networks Junos OS 异常处理不当漏洞  
  
发布日期：2026-10-14  
  
受影响系统：Juniper Networks Junos OS 23.2R2-S7.7之前版本  
  
23.4版本至23.4R2-S8.13之前版本  
  
24.2版本至24.2R2-S5.5之前版本  
  
24.4版本至24.4R2-S5之前版本  
  
25.2版本至25.2R2-S2之前版本  
  
25.4版本至25.4R1-S3之前版本和26.2版本至26.2R1-S2之前版本  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2026-101973  
  
Juniper Networks Junos OS是美国Juniper Networks公司的一款专为路由器、交换机和防火墙等物理及虚拟设备打造的网络操作系统。  
  
Juniper Networks Junos OS 23.2R2-S7.7之前版本、23.4版本至23.4R2-S8.13之前版本、24.2版本至24.2R2-S5.5之前版本、24.4版本至24.4R2-S5之前版本、25.2版本至25.2R2-S2之前版本、25.4版本至25.4R1-S3之前版本和26.2版本至26.2R1-S2之前版本存在异常处理不当漏洞，该漏洞源于pkid组件存在空指针取消引用，可能导致未经身份验证的远程攻击者通过CMP注册或自动证书重新注册期间接收的畸形数据包造成拒绝服务。  
  
链接：  
  
https://supportportal.juniper.net/JSA112188  
  
建议：  
  
目前厂商已发布升级补丁以修复漏洞，补丁获取链接：  
  
https://supportportal.juniper.net/JSA112188  
  
F5 NGINX Gateway Fabric 授权问题漏洞  
  
发布日期：2026-10-14  
  
受影响系统：  
  
F5 NGINX Gateway Fabric 2.0.0版本至2.8.0之前版本  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2026-96615  
  
F5 NGINX Gateway Fabric是美国F5公司的一个面向Kubernetes环境的应用流量网关。  
  
F5 NGINX Gateway Fabric 2.0.0版本至2.8.0之前版本存在授权问题漏洞，该漏洞源于配置Gateway CRD并启用与NGINX Agent的经过身份验证的gRPC连接时，拥有服务账户访问权限的命名空间内经过身份验证的攻击者可冒充该gRPC连接，可能导致读取其他命名空间中Gateway部署的TLS私钥。  
  
链接：  
  
https://my.f5.com/manage/s/article/K000162610  
  
建议：  
  
厂商已发布了漏洞修复程序，补丁获取链接：  
  
https://my.f5.com/manage/s/article/K000162610  
  
Linux kernel 安全漏洞  
  
发布日期：2026-10-14  
  
受影响系统：  
  
Linux kernel 5.19版本  
  
描述：  
  
BUGTRAQ ID:   
  
CVE(CAN) ID:CVE-2026-98410  
  
Linux kernel是美国Linux基金会开源的一个操作系统内核。  
  
Linux kernel 5.19版本存在安全漏洞，该漏洞源于da9063_wdt_suspend()和da9063_wdt_resume()仅检查watchdog_active()，未正确处理WDOG_HW_RUNNING，导致看门狗在系统挂起期间继续计数，可能造成意外系统复位。  
  
链接：  
  
https://git.kernel.org/stable/c/1c42e39b0990371b9d76ae22c3f33eb6df341251  
  
建议：  
  
厂商已发布了漏洞修复程序，补丁获取链接：https://www.kernel.org/
