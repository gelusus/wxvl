Oracle Access Manager身份验证不当漏洞漏洞  
  
发布日期：2026-11-05  
  
受影响系统：  
  
Oracle Access Manager 12.2.1.4.0  
  
Oracle Access Manager 14.1.2.0.0  
  
描述：  
  
CVE(CAN) ID: CVE-2026-83409  
  
Oracle Access Manager是Oracle公司出品的单点登录（SSO）和访问管理软件。  
  
Oracle Access Manager存在身份验证不当漏洞，该漏洞源于Authentication Engine组件问题，攻击者可利用该漏洞通过SAML网络访问，导致Oracle Access Manager被接管。  
  
链接：  
  
https://nvd.nist.gov/vuln/detail/CVE-2026-83409  
  
建议：  
  
目前厂商已经发布了升级补丁以修复这个安全问题，请到厂商的主页下载：  
  
https://www.oracle.com/security-alerts/cpuoct2026.html  
  
Apache OFBiz服务端请求伪造漏洞  
  
发布日期：2026-11-09  
  
受影响系统：  
  
Apache OFBiz <24.09.08  
  
描述：  
  
CVE(CAN) ID: CVE-2026-82902  
  
Apache OFBiz是Apache软件基金会旗下的一个顶级开源项目，本质上是一套基于Java的企业资源规划（ERP）系统，也常被用作电子商务平台。  
  
Apache OFBiz存在服务端请求伪造漏洞，该漏洞源于ViewDataFile.groovy将viewdatafile界面中的DEFINITION_LOCATION或DATAFILE_LOCATION请求参数作为java.net.URL对象解引用，且没有协议白名单、主机过滤或出口控制，并在权限检查前执行，攻击者可利用该漏洞发起任意出站HTTP请求或读取本地文件。  
  
链接：  
  
https://nvd.nist.gov/vuln/detail/cve-2026-82902  
  
建议：  
  
目前厂商已经发布了升级补丁以修复这个安全问题，请到厂商的主页下载：  
  
https://lists.apache.org/thread.html/7b2syzksp7klt9fvhdg0olldvs2g83lz  
  
Red Hat Enterprise Linux命令注入漏洞  
  
发布日期：2026-11-11  
  
受影响系统：Red Hat Enterprise Linux 7  
  
Red Hat Enterprise Linux 8  
  
Red Hat Enterprise Linux 9  
  
Red Hat Enterprise Linux 10  
  
Red Hat OpenShift Container Platform 4  
  
Red Hat OpenShift Container Platform 5  
  
描述：  
  
CVE(CAN) ID: CVE-2026-108472  
  
Red Hat Enterprise Linux是美国Red Hat公司的一款操作系统产品。  
  
Red Hat Enterprise Linux 7版本、8版本、9版本和10版本以及Red Hat OpenShift Container Platform 4版本和5版本存在命令注入漏洞，该漏洞源于xfsprogs中的xfs_admin工具未正确验证用户提供的参数，本地攻击者可利用该漏洞通过提供特制输入参数执行任意命令并提升本地权限，具体取决于xfs_admin的执行方式。  
  
链接：  
  
https://access.redhat.com/security/cve/CVE-2026-108472  
  
建议：  
  
厂商尚未提供漏洞修复方案，请关注厂商主页更新：  
  
https://access.redhat.com/security/cve/CVE-2026-108472  
  
Red Hat Quay SQL注入漏洞  
  
发布日期：2026-11-11  
  
受影响系统：  
  
Red Hat Quay 3  
  
Red Hat Quay 5  
  
描述：  
  
CVE(CAN) ID:CVE-2026-110697  
  
Red Hat Quay是美国Red Hat公司的一个容器镜像仓库管理组件。  
  
Red Hat Quay 3版本和5版本存在SQL注入漏洞，该漏洞源于机器人账户列表功能在根据用户控制的命名空间名称构建SQL LIKE模式时未转义通配符元字符，攻击者可利用该漏洞通过创建包含下划线的命名空间匹配并获取其他租户的机器人账户及解密身份验证令牌，导致跨租户凭据窃取和未经授权的镜像操作。  
  
链接：  
  
https://access.redhat.com/security/cve/CVE-2026-110697/  
  
建议：  
  
厂商尚未提供漏洞修复方案，请关注厂商主页更新：  
  
https://access.redhat.com/security/cve/CVE-2026-110697/
