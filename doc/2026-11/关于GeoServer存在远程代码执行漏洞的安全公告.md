#  关于GeoServer存在远程代码执行漏洞的安全公告  
原创 CNVD
                    CNVD  CNVD漏洞平台   2026-11-25 04:37  
  
安全公告编号:CNTA-2026-0008  
  
  
2026年11月25日，国家信息安全漏洞共享平台（CNVD）收录了GeoServer远程代码执行漏洞（CNVD-2026-47957、CNVD-2026-47958、CNVD-2026-47959、CNVD-2026-47960、CNVD-2026-47961）。未经身份验证的远程攻击者组合利用上述漏洞，可在默认配置条件下获读取服务器端安全配置、获取管理员会话，并以GeoServer服务进程权限执行代码。目前，漏洞技术细节与PoC已传播，CNVD建议受影响用户立即升级至最新版本。  
  
  
一、漏洞情况分析  
  
GeoServer  
是一个基于  
Java  
语言开发的开源地理空间数据服务器，提供政务、测绘、自然资源以及行业  
GIS  
平台的图层空间数据发布等功能，在政府与行业地理信息基础设施中部署较广。  
Web  
要素服务（  
WFS  
）是  
GeoServer  
提供的标准化  
Web  
服务，用于矢量要素数据的发布和访问，是业务系统调用地图图层的常用接口。  
  
2026  
年  
11  
月  
23  
日，  
GeoServer  
发布安全公告，修复了远程代码执行漏洞链，该利用链由五个漏洞构成：  
  
1  
、  
WFS  
存储查询处理超长标识时缺少长度限制，异常信息回显完整文件系统路径，泄露数据目录位置。（  
CNVD-2026-47961  
，对应  
CVE-2026-129244  
）  
  
2  
、服务调度器对带路径分隔符的服务名截断解析，访问控制规则仍按原始值匹配而被绕过，匿名用户可创建、删除存储查询。（  
CNVD-2026-47960  
，对应  
CVE-2026-129243  
）  
  
3  
、存储查询文本在重载时被二次解析，实体解析允许本地文件协议，可经  
XInclude  
读取数据目录中的安全配置文件。（  
CNVD-2026-47959  
，对应  
CVE-2026-120705  
）  
  
4  
、  
remember-me  
签名密钥沿用固定默认值，配合泄露的用户口令摘要来伪造管理员会话。（  
CNVD-2026-47958  
，对应  
CVE-2026-129245  
）  
  
5  
、  
JDBC  
用户服务以对象方式读取用户属性，底层数据库驱动对存储字节执行无过滤反序列化。（  
CNVD-2026-47957  
，对应  
CVE-2026-129242  
）  
  
未经身份验证的远程攻击者通过默认开放的  
WFS  
服务入口，依次利用上述漏洞，可在默认配置条件下获读取服务器端安全配置、获取管理员会话，并以  
GeoServer  
服务进程的权限执行代码：以官方容器镜像默认配置部署时，  
GeoServer  
进程以  
root  
运行，攻击者可获最高权限；以普通用户身份部署时，受进程权限约束，仍能导致空间数据与配置泄露、服务中断或主机被进一步控制。  
  
CNVD  
对上述漏洞的综合评级为“高危”。  
  
  
二、漏洞影响范围  
  
目前，已知受漏洞影响的  
GeoServer  
产品版本包括：  
  
GeoServer <= 2.27.6  
  
GeoServer 2.28.0 - 2.28.5  
  
GeoServer 3.0.0 - 3.0.1  
  
  
三、漏洞处置建议  
  
目前，  
GeoServer  
官方已发布新版本修复漏洞，  
CNVD  
建议受影响用户尽快进行自查，通过官方链接升级至  
 3.0.2  
、  
2.28.6  
或  
2.27.7  
及对应分支的更高版本。  
  
https://geoserver.org/download/
