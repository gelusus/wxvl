## 01  本期概览  
  
10 月 25 日到 11 月 1 日这一周，高危数量不算多，但结构很难受：6 个已经在野外被打了，32 个评分 9.0 以上，其中一批是边界设备和 CI 平台。  
  
只看一个洞的话，看 GitLab。CI/CD 配置里一个正则就能让未认证的人在你服务器上执行代码，而 GitLab 服务器上通常躺着源码、镜像仓库凭证和部署密钥。打进一台 GitLab，等于拿到整条研发流水线。第二个是 Ivanti Connect Secure 的两条链式漏洞，一个提权到 root，一个能往磁盘任意位置写文件，拼起来就是边界设备上的持久化。  
  
剩下的看资产清单：有 Juniper Session Smart Router 的、跑 LMDeploy 推理服务的、装了一堆 WordPress 插件的，往下翻到对应条目。  
  
## 02  在野利用，先修这个  
  
  
CVE-2026-97229  
在野利用  
  
GitLab CE/EE 未认证 RCE。正则校验不够严，在 CI/CD 配置里塞一个构造过的正则就能触发整数溢出，最终变成服务端任意代码执行，全程不用登录、不用受害者点击。  
  
影响 19.2 至 19.2.8 前、19.3 至 19.3.5 前、19.4 至 19.4.2 前 / 升到对应修复版本，公网暴露的先摘下来  
  
CVE-2026-111357  
在野利用  
  
Ivanti Connect Secure 提权到 root。dsinvoked broker 在处理 DSCache 配置数据的信任关系上出了问题，本地已认证的低权限用户可以直接提到 root，10 月已在野外被利用。  
  
影响 22.8R2.4 / 打补丁并排查 10 月以来的异常登录  
  
CVE-2026-118527  
在野利用  
  
Ivanti Connect Secure 任意位置写文件。随机数可预测，远程已认证攻击者能把内容可控的文件落到磁盘上已知位置，还能与 CVE-2026-111357、CVE-2026-104935 串成链。  
  
与上面一条同时修 / 两条要当成一组看  
  
CVE-2026-109619  
在野利用  
  
PHP 未认证 RCE。指向请求内存的全局状态没被正确重置，请求内存释放后这些状态仍然指着那块地址，后续请求会在初始化之前读陈旧状态并据此分支，多条路径都能走通。  
  
所有维护中的 PHP 分支 / 升到当前维护版最新小版本  
  
CVE-2026-111497  
在野利用  
  
Google Brotli 解码器缓冲区溢出。构造过的压缩流能破坏相邻解码器状态内存、泄露内存内容、打成拒绝服务，条件合适可直接执行代码。远程未认证。  
  
影响 1.0.3 至 1.2.0 / 不止浏览器，凡链接 libbrotli 的服务都算  
  
CVE-2026-46300  
在野利用  
  
Linux 内核 page cache 数据可被非预期修改。socket buffer 合并时没保住共享 fragment 标记，ESP 输入处理会原地解密共享分片。危险的不是单点执行，是它动的是内核缓存层。  
  
跟进发行版内核更新 / 有 IPsec 的场景优先  
  
## 03  CVSS 9.0 以上紧急项  
  
  
CVE-2026-103409  
9.8 紧急  
  
Juniper Session Smart Router，未认证攻击者构造 URL 参数打到以 root 运行的不安全端点，直接拿管理员权限。前提是设备还没 onboard 到 Mist/Conductor，上架流程中、尚未接管的路由器现在是敞着的。  
  
onboard 前先断公网，再走升级  
  
CVE-2026-105781 等四个  
10.0 紧急  
  
Adobe Campaign Classic SQL 注入到当前用户上下文的任意代码执行，不需要用户交互。同批还有 104351 代码注入 9.9、104353 OS 命令注入 9.9、105780 越权 9.9，低权限账号就是起点。  
  
营销平台往往接着客户库，价值在数据 / 四个一起打补丁  
  
CVE-2026-116506  
9.9 紧急  
  
TOTOLINK A950RG 命令注入，firewall.so 的 apmib_set 函数，远程可打，利用代码已经公开。这类设备没有集中升级通道，公开 PoC 出来后一周内就会被扫烂。  
  
固件 4.1.2cu.5268_B20221104 / 换固件或直接换设备  
  
CVE-2026-119706  
9.8 紧急

影响 0.9.0 至 0.18.0 / 升级并收回公网访问  
  
CVE-2026-112346  
9.8 紧急  
  
OpenHands Agent SDK 未认证 RCE。DockerWorkspace 和 Apptainer 把 sandbox agent server 绑到 0.0.0.0，session_api_keys 却是空列表，等于默认关掉认证，能连到映射端口就能发未认证请求。  
  
影响 1.52.0 之前 / 沙箱不该对着公网开  
  
CVE-2026-120201  
9.8 紧急

MuseBot 认证绕过。默认 session_key 写死在代码里，就是 muse_bot_session_key。攻击者自己签一个带 user_id 的 cookie 就是管理员，能读密码哈希、聊天记录、机器人配置。

## 04  值得关注  
  
WordPress 生态这周很热闹，五条 9.0 以上，全部集中在插件层。  
  
SimpleForm 3.10.2 及以下  
，handle_upload 缺文件后缀白名单，文件名末尾加个点就能绕过扩展名和 MIME 校验，任意文件上传 9.8。  
  
Uncanny Toolkit 3.8.2 及以下  
，登录逻辑存在解析差异：校验环节用原始 email 查用户，后续用清洗后的值，两边认的不是同一个人，认证直接绕过。  
  
WooCommerce PDF Invoice 7.1.1 及以下  
，customer_note 结账字段没洗干净，PHP 对象注入，9.8。  
  
Project Manager 4.1.1 及以下  
，id 参数拼接执行，9.8 远程代码执行；同批 Popup Builder 4.4.5 及以下权限校验缺失，9.1 越权。  
  
另有几套国产与建站系统  
：REDAXO 5.21.4 之前可伪造临时登录令牌 9.8，MacCMS v10 可重置任意会员密码 9.1，Oray 蒲公英 X5 Pro 7.6.1 的 IPsec 配置 CRLF 注入 9.1。  
  
共同点很明显：都不是内存层面的硬功夫，全是校验缺位和解析差异。公开 PoC 出来之后，改一改参数就能批量打，不需要什么利用技巧。

## 06  一句判断  
  
GitLab 和 Ivanti 这两个今晚就该动，不是明天。前者未认证打服务器，后者打的是边界而且已经在野。剩下的按资产清单排队，路由器类和 AI 推理服务往前放——不是这两类洞多，是配置习惯性地把执行入口敞在公网上。
