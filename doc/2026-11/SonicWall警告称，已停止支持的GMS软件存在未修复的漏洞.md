#  SonicWall警告称，已停止支持的GMS软件存在未修复的漏洞  
原创 ZM
                    ZM  暗镜   2026-11-10 22:00  
  
SonicWall 警告客户，已停止支持的全球管理系统 (GMS) 系统存在两个安全漏洞，这些漏洞将不会得到修补。  
  
全球管理系统 (GMS) 可帮助 IT 管理员通过单一界面部署和管理数千台 SonicWall 安全设备，但 SonicWall 已正式用网络安全管理器 (NSM) 管理平台取代了它。  
  
这两个漏洞是由 Pentest-Tools 安全研究人员发现并报告的，会影响运行 SonicWall GMS 9.5.2 及更早版本的系统。近期  
  
披露的第一个 GMS 漏洞被追踪为CVE-2026-109593，它允许未经身份验证的攻击者通过网络访问易受攻击的实例（运行 GMS 9.5.2 及更早版本）来读取内部文件，从而窃取敏感信息。  
  
SonicWall 还指出了第二个安全问题（CVE-2026-109594），该问题可能允许具有高权限的威胁行为者通过低复杂度的 SQL 注入攻击访问或修改存储在 GMS 数据库中的信息。  
  
SonicWall还敦促客户升级到 NMS，因为存在漏洞的系统现在已经达到使用寿命终点，它将不再发布安全补丁。  
  
SonicWall周二警告称：“受影响的产品已达到产品生命周期结束（EOL）。因此，不会针对这些漏洞发布任何修复程序或安全更新。”  
  
“使用该产品的组织应意识到相关的安全风险，强烈建议其升级到 SonicWall 网络安全管理器 (NSM)。”  
  
攻击者经常以 SonicWall 的漏洞为目标，并且自今年年初以来，已经利用了多个漏洞发动了零日攻击。  
  
今年2月，SonicWall要求客户修补两个SMA1000零日漏洞（CVE-2026-15409和CVE-2026-15410）， 7月又修补了另外两个零日漏洞（CVE-2026-15409和CVE-2026-15410）。此外，该公司还在9月（CVE-2026-83548和CVE-2026-83549）和10月（CVE-2026-102255）修补了另外三个被利用为零日漏洞的SMA1000漏洞。  
  
在过去的四年里，美国网络安全和基础设施安全局 (CISA) 将 19 个 SonicWall 漏洞添加到其活跃利用的漏洞列表中，其中 13 个漏洞也被勒索软件团伙滥用。SonicWall 通过超过 17,000 个合作伙伴的网络，为 215 多个国家和地区的 500,000 多个客户提供服务（包括中小企业、大型企业和政府机构）。
