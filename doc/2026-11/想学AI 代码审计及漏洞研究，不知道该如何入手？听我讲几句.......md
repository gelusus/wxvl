## 一、简述  
  
代码审计及漏洞研究的工作方式，正在被 AI 重新定义。  
  
当大模型已经能够读懂程序逻辑、推断数据流向，当智能体可以自主调用静态分析工具、检索安全知识库，代码审计的效率与深度都进入了新的阶段。  
  
但真正驾驭 AI 做审计，并不是简单地向聊天工具提问、套用几个提示词，而是需要同时具备扎实的代码审计功底，以及工程化使用大模型的能力。

### （二）当前更新主线：AI 赋能 Java 与 PHP 代码审计  
  
本模块为当前持续更新的重点，规划 **10 大方向、50+ 课时**  
，采用 “原理录播 + 实战直播带练” 的方式推进，内容随技术发展只增不减。目标是带学员完成一个能够自主运行的代码审计智能体。（目前正在火热更新中......）  
1. **大模型底层知识**  
  
理解 Transformer、自注意力机制、代码分词与嵌入，掌握温度、Top-p 等解码策略对审计结果确定性的影响，学会评估 AI 审计工具的精确率与召回率，从底层告别黑箱使用。  
  
1. **漏洞检测模型训练**  
  
理解预训练任务如何让模型学会 Java 语义，基于 CodeBERT/GraphCodeBERT 微调漏洞分类器，掌握数据增强、模型量化与 ONNX 本地部署，构建自己的漏洞检测引擎。  
  
1. **攻防提示工程实战**  
  
建立审计专用提示模板库，运用思维链推演 “输入源 → 数据流 → 危险函数”，掌握强制结构化输出、少样本示例与防幻觉策略，让模型稳定输出带行号的漏洞分析与修复建议。  
  
1. **RAG 安全知识库**  
  
掌握文档切片、嵌入模型选型与向量检索，将 OWASP 指南、CWE 百科、安全编码规范与漏洞报告向量化存储，搭建检索增强审计链路，让每一次判断都有据可依，抑制模型幻觉。  
  
1. **MCP 协议与工具生态**  
  
基于 MCP 协议实现模型对工具的自动发现与精准调用，掌握工具描述编写与权限控制，构建可扩展、即插即用的代码审计工具生态。  
  
1. **Skill 模块化能力封装**  
  
将各类漏洞检测能力封装为可插拔 Skill，明确输入输出 Schema 与依赖工具，构建能力注册机制并编写单元测试，保证能力持续迭代而不退化。  
  
1. **专属代码审计智能体**  
  
整合前述技术，实现 “感知 → 规划 → 执行 → 反思” 的完整闭环，实践 ReAct、Plan-Execute 等规划策略，加入记忆管理与安全沙箱，交付一个能自主遍历项目、调用工具、生成审计报告的 Agent。  
  
1. **A2A 多智能体协同**  
  
构建多 Agent 协同审计工作流，将信息收集、静态分析、语义审计、报告撰写等任务分配给专用智能体，实现审计过程的自动分工与并行推进。  
  
1. **顶级 AI 攻防项目拆解**  
  
逐行拆解业界代表性 AI 安全项目的源码与架构，提炼多智能体协作、规则生成、提示模板设计等可复用的设计模式，把高手的思路转化为自己的方法库。  
  
1. **真实系统综合实战**  
  
将整套方法应用于真实 Java 系统与课程靶场，完成从项目导入到审计报告导出的全流程验证，并将方法论迁移到任意内部代码库，形成可持续优化的个人审计系统。  
  
**跨语言延伸：AI 阶段穿插 PHP 代码审计**  
  
在 AI 主线更新中，除 Java 外还将穿插讲解 PHP 代码审计相关知识点。提示工程、RAG、Agent、MCP、Skill 等核心方法并不绑定单一语言，配合 PHP 审计场景的实战穿插，帮助学员把同一套 AI 审计方法论迁移到更多语言与场景，全面打造覆盖多语言的 AI 代码审计与漏洞研究攻防实战能力。
