#  Palo Alto Networks警告称，Fragnesia漏洞已被恶意利用  
原创 ZM
                    ZM  暗镜   2026-11-26 23:00

Palo Alto 11 月 25 日发布的安全公告列出了 PAN-OS 五个版本分支的修复程序，并呼吁在管理访问权限仍可公开访问的情况下立即进行升级。Palo Alto Networks 已确认Fragnesia漏洞已被实际利用，该漏洞是一个影响 PAN-OS 的 Linux 内核权限提升漏洞。该漏洞编号为 CVE-2026-46300，已被用于攻击那些管理接口暴露于互联网的设备。  
  
Fragnesia 漏洞是一个本地权限提升漏洞，而非独立的远程入口点。Palo Alto Networks 表示，目前已知的唯一攻击路径是通过面向互联网的管理界面利用 PHP2Shell 漏洞发起攻击。Fragnesia 允许攻击者在获得初始立足点后提升权限。此前关于针对 Palo Alto 防火墙的 PHP2Shell 攻击的报道也描述了同样的攻击链，最终导致攻击者获得受影响设备的 root 权限。这一区别对于补丁优先级的确定至关重要。Palo Alto Networks 将该公告标记为“信息性公告”，因为它涉及一个开源组件。然而，该公司也单独确认了针对已暴露设备的漏洞利用。Linux内核漏洞属于页面缓存漏洞家族，Linux 将文件数据存储在页面缓存中。在此次攻击活动中，该内核漏洞被用作权限提升阶段，而非从互联网访问防火墙的手段。PAN-OS 10.2 的修复版本包括 10.2.7-h41、10.2.10-h45、10.2.13-h29、10.2.16-h14 和 10.2.18-h15。对于 11.1，公告列出了 11.1.4-h40、11.1.6-h42、11.1.7-h14、11.1.10-h38、11.1.13-h18 和 11.1.16-h6。11.2 版本的修复程序包括 11.2.4-h25、11.2.7-h25、11.2.10-h19、11.2.13-h6 和 11.2.16-h3。其余列出的版本为 12.1.4-h15、12.1.7-h15、12.1.10-h6 和 12.2.4-h3。管理员应将已安装的维护版本与相应的修复版本或更高版本相匹配。security.paloaltonetworks此前针对PAN-OS管理接口的攻击也曾出现过公开暴露的情况。对于Fragnesia系统，无论互联网访问是通过专用管理接口还是附加了管理配置文件的数据平面接口实现的，都建议立即升级。组织应该将管理访问权限限制在受信任的内部 IP 地址，而不是在打补丁后让接口可以公开访问。Palo Alto Networks 表示，对于已经具备管理接口且仅接受来自受信任的内部 IP 地址的连接的设备而言，风险要低得多。该公司建议在下次维护窗口期间进行升级。此外，运行其 PHP2Shell 安全公告中指定的固定 PAN-OS 版本的客户可以免受已知攻击途径的影响。
