最近在翻各大安全社区的 advisory 时，看到了一个让人相当窒息的操作——**SonicWall 官方公开宣布，对于其 Global Management System (GMS) 爆出的两个高危漏洞，他们不准备发补丁了。**  
  
简单来说，只要你在用 **GMS 9.5.2 及更早版本**  
，就相当于系统处于“裸奔”状态。官方给出的理由也很简单粗暴：“该产品已经达到生命周期终点（EoL），大家赶紧掏钱升级到最新的 Network Security Manager (NSM) 吧。”  
  
作为技术人，咱们今天不吐槽这波商业操作，重点来扒一扒这俩漏洞的技术细节。它们到底是怎么被利用的？破坏力有多大？  
## 🔓 漏洞解析一：未授权文件读取 (CVE-2026-109593)  
  
**CVSS 评分：9.1 (极度高危)**  
  
这个漏洞可以说是纯粹的“门没锁”。只要攻击者处于你的网络覆盖范围内，**无需任何身份验证**  
，就能直接读取 GMS 系统内部的核心文件。  
  
**技术原理剖析：**  
  
这类漏洞通常是因为后台处理 Web 请求时，对用户输入的路径参数缺乏严格的过滤（比如没有做好完整的   
Directory Traversal  
 路径穿越防御），或者存在直接对象引用（IDOR）问题。攻击者通过构造恶意的 HTTP 请求载荷（Payload），例如利用   
../../  
 类的路径穿越，或者直接访问那些本该被鉴权中间件拦截的系统配置文件路径，就能绕过限制。  
  
**危害与重现思路：**  
  
试想一下，如果读取的是包含数据库连接串、API 密钥甚至是加密证书的   
.config  
 或   
.properties  
 文件，那整个系统的防线就不攻自破了。重现这类漏洞，通常用 Burp Suite 抓个包，针对特定的 API 接口（特别是那些负责处理日志读取、文件导出的遗留接口）进行 Fuzzing，很容易就能把敏感数据拉出来。  
## 💉 漏洞解析二：后认证 SQL 注入 (CVE-2026-109594)  
  
**CVSS 评分：6.8 (中高危)**  
  
虽然这个漏洞需要攻击者已经拥有了一个账号，但千万别掉以轻心。一旦绕过认证，攻击者就能在特定条件下对 GMS 的数据库进行数据的读取或篡改。  
  
**技术原理剖析：**  
  
老生常谈的 SQL 注入。GMS 在处理某些管理后台的表单提交或数据查询请求时，很显然**没有强制使用预编译语句**  
。攻击者可以在查询参数中闭合原本的 SQL 语句（比如   
'; DROP TABLE users; --  
），把恶意的 SQL 逻辑拼接到原始查询中传给底层数据库执行。  
  
**实现难点：**  
  
官方强调了“在特定条件下”。这就意味着这不是一个单纯的基于错误回显的注入。很可能需要利用盲注（Blind SQLi，如基于时间的   
SLEEP()  
 或布尔条件）来一点点渗出数据。这种注入利用起来比较耗时，但一旦成功，就能拿到管理员权限甚至执行提权。  
## ⚠️ 前车之鉴：满分漏洞正在被疯狂利用  
  
别以为不发补丁只是个例，GMS 这套系统最近可以说是千疮百孔。  
  
不到一个月前，SonicWall 刚修复了一个 **CVSS 评分直接拉满 10.0 的神仙级漏洞（CVE-2026-102255）**  
。这是一个未授权的服务器端请求伪造。通过 SSRF，攻击者能把 GMS 当作跳板机，直接打进企业的内网，执行各种非法操作。  
> 来自一线的实战数据：  
> 根据安全机构 Previdian 的遥测数据，自 2026 年 10 月 9 日以来，野外已经监测到了 **2,541 次**  
 针对该 SSRF 漏洞的疯狂攻击！这些攻击源主要来自新加坡和美国的 8 个独立 IP。就在11 月 3 日，一天内依然有 30 次猛烈的 Exploit 尝试。这说明黑客的自动化扫描脚本已经在满世界找漏网之鱼了。  
  
  
## 💡 咱们的破局思路  
  
对于依然在维护 GMS 老版本的老铁们，现在的局面非常被动。既然官方断了粮（补丁），我们只能从架构层做防御：  
1. **强行隔离**  
立刻把 GMS 服务器从公网暴露面撤下，严格限制访问 ACL。只允许通过 VPN 或者零信任网关来进行管理访问。  
  
1. **上 WAF 策略**  
针对文件读取（过滤   
../  
 等特征）和 SQL 注入增加定制化的 Web 应用防火墙拦截规则，用正则把疑似 Payload 的请求全掐死。  
  
1. **顺势重构**  
说实话，EoL 的系统就像一颗定时炸弹。如果预算允许，尽早听从官方建议迁移到 **NSM才是长治久安的方案。**
