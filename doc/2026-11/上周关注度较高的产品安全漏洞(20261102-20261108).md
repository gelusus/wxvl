#  上周关注度较高的产品安全漏洞(20261102-20261108)  
原创 CNVD
                    CNVD  CNVD漏洞平台   2026-11-11 02:50  
  
一、境外厂商产品漏洞  
  
1、OpenBSD OpenSSH sshd密码认证绕过漏洞  
  
OpenSSH是一款广泛使用的开源SSH协议实现套件，sshd是其服务端守护进程，主要提供安全的远程登录与加密通信功能。OpenBSD OpenSSH sshd存在密码认证绕过漏洞，该漏洞源于Linux系统使用musl libc且禁用PAM时，缺少对密码认证绕过的有效验证所致，与是否将字符串误解为密码哈希有关，攻击者可利用该漏洞绕过密码认证。  
  
参考链接：  
  
https://www.cnvd.org.cn/flaw/show/CNVD-2026-44652  
  
2、Apple iOS缓冲区溢出漏洞（CNVD-2026-44037）  
  
Apple iOS是Apple的一款移动操作系统，主要用于iPhone和iPad等苹果移动设备。Apple多款产品存在缓冲区溢出漏洞，该漏洞源于边界检查不当导致越界写入，处理恶意特制文件可能导致任意代码执行。攻击者可利用该漏洞导致任意代码执行。  
  
参考链接：  
  
https://www.cnvd.org.cn/flaw/show/CNVD-2026-44037  
  
3、Microsoft Windows Update Stack本地权限提升漏洞  
  
Windows 11（简称Win11）是微软开发的桌面操作系统，2021年10月5日正式推送，为Windows 10的后续版本。Windows Server 2025是微软公司研发的服务器操作系统，于2024年11月1日正式发布，接替前代系统Windows Server 2022。Windows Server 2025 (Server Core installation)是一款不带本地图形用户界面（GUI）的精简版本，包含Windows Server的核心组件并支持所有服务器角色，专为“无头”部署设计，通过远程工具管理。Microsoft Windows Update Stack存在本地权限提升漏洞，该漏洞源于Windows更新堆栈时，未对访问文件前的链接进行正确的解析所致，具有权限的攻击者可利用漏洞进行本地权限提升。  
  
参考链接：  
  
https://www.cnvd.org.cn/flaw/show/CNVD-2026-44110  
  
4、JetBrains TeamCity代码执行漏洞（CNVD-2026-44054）  
  
JetBrains TeamCity是由JetBrains公司开发的持续集成（CI/CD）工具‌。JetBrains TeamCity存在代码执行漏洞，该漏洞源于Git VCS根目录在处理特定配置时未能正确处理输入，攻击者可利用该漏洞在受影响的系统上执行任意代码。  
  
参考链接：  
  
https://www.cnvd.org.cn/flaw/show/CNVD-2026-44054  
  
5、Google Chrome for Windows释放后使用漏洞  
  
Google Chrome for Windows是谷歌开发的网页浏览器Windows版本。Google Chrome for Windows存在释放后使用漏洞，该漏洞源于Browser组件存在释放后使用漏洞，攻击者可利用该漏洞通过特制HTML页面在沙箱内执行任意代码。  
  
参考链接：  
  
https://www.cnvd.org.cn/flaw/show/CNVD-2026-43349

Xiaomi Mi Connect Service APP是小米官方推出的跨设备互联工具。Xiaomi Mi Connect Service APP存在未授权访问漏洞，该漏洞源于验证逻辑缺陷，攻击者可利用该漏洞未授权访问设备。  
  
参考链接：  
  
https://www.cnvd.org.cn/flaw/show/CNVD-2026-43365  
  
2、Dahua EIMS命令注入漏洞  
  
Dahua EIMS是浙江大华技术股份有限公司的企业信息管理系统。Dahua EIMS存在命令注入漏洞，该漏洞源于captureCommand参数的输入验证不当，该参数在未经净化或身份验证的情况下被处理。攻击者可利用该漏洞导致任意命令执行。  
  
参考链接：  
  
https://www.cnvd.org.cn/flaw/show/CNVD-2026-43364  
  
3、YeaLink SIP-T46U栈缓冲区溢出漏洞  
  
YeaLink SIP-T46U是一款高端彩屏无纸化IP话机。YeaLink SIP-T46U存在栈缓冲区溢出漏洞，该漏洞源于Web FastCGI Service中bttest文件的mod_webd.BlueToothTest函数未能正确验证参数btMac/pin/reserved长度，目前没有详细的漏洞细节提供。  
  
参考链接：  
  
https://www.cnvd.org.cn/flaw/show/CNVD-2026-43363  
  
4、DJI CrystalSky ZS600C缺少授权漏洞  
  
DJI CrystalSky ZS600C是大疆（DJI）CrystalSky高亮显示屏系列中的一款型号，对应5.5英寸高亮版。DJI CrystalSky ZS600C存在缺少授权漏洞，该漏洞源于系统特权DJIUpdateService binder缺少授权，onTransact()未执行调用者身份或权限检查，攻击者可利用该漏洞在无权限情况下执行设备恢复出厂设置、关机、修改时钟/时区等特权操作，导致设备被篡改或不可用。  
  
参考链接：  
  
https://www.cnvd.org.cn/flaw/show/CNVD-2026-43362

Tenda AC5是腾达（Tenda）推出的一款入门级1200M双频家用无线路由器‌。Tenda AC5存在缓冲区溢出漏洞，该漏洞源于initWebs函数对于用户输入的数据缺乏长度检查，目前没有详细的漏洞细节提供。
