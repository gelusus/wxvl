## 02  在野利用（先修这个）  
  
  
CVE-2026-90436  
9.8 无补丁  
  
Apache Axis 1.x 不安全反射。构造一个 SOAP fault，让 Axis 加载 classpath 上任意类并调用它的字符串构造函数，未认证就能执行代码。Axis 已停止维护，Apache 不会发补丁。真正中招的是内嵌它的产品：Confluence Data Center 1.x 到 9.x（开启 Remote API 时）、N-able N-central（Legacy API 开启时）。  
  
在野实况：未认证 POST 打到 /plugins/servlet/soap-axis1/confluenceservice-v2 返回 500，但 bash 与 curl 已经以 confluence 账户拉起；3 分钟后攻击者用 Confluence 自己的数据库口令登进 MySQL，4 小时拿到云数仓凭证，12 小时用集成账号登录微软 365。  
  
修复：Confluence 升 9.2.28 或 10.x；或在后台清掉 Remote API（XML-RPC 与 SOAP）开关，立即生效、不用重启。N-central 升 2026.4 HF3。  
  
CVE-2026-76466  
9.8 已修  
  
Cisco Expressway 系列集群设备的数据库服务用持久 cookie，TLS Verify Mode 打开时客户端证书也没被真正校验。拿到 cookie 连上数据库服务发特定 RPC，就能以 root 执行命令。  
  
影响 Expressway-C 与 Expressway-E 的集群配置，X15.5.3 及更早；修复版 X15.5.20，X14 只能迁移，官方没有 workaround。10 月发补丁，PoC 流出后很快出现利用。  
  
CVE-2026-129448  
9.8 已修  
  
Apache Roller 的 XML-RPC 端点接受 vendor extension 类型，并在认证之前就把它反序列化，发一个 ex:serializable 就能塞进 Java 序列化链执行代码。  
  
4.0.0 到 6.1.5 中招，升级 6.1.6，官方建议直接 6.1.7。临时缓解要在 WEB-INF/web.xml 把 enabledForExtensions 设为 false，或删掉 /roller-services/xmlrpc 映射；在后台 UI 关 XML-RPC 没有用。  
  
CVE-2025-42884  
6.5 已修  
  
SAP NetWeaver Enterprise Portal 的 JNDI 注入。未认证攻击者注入 JNDI 环境属性或指定 lookup 用的 URL，把服务器导向攻击者自己的 provider，可读改服务器信息。  
  
影响 EP-BASIS 与 EP-RUNTIME 7.50，修 SAP Note 3660969。2025 年 11 月就修了，一年后才因为出现在野外进 KEV。  
  
CVE-2026-40217  
8.8 已修  
  
LiteLLM 的沙箱逃逸。POST /guardrails/test_custom_code 在手写沙箱里跑用户提交的 Python，用字节码技巧绕出去，就在 proxy 进程里执行任意代码；默认 Docker 镜像里这个进程是 root。  
  
1.81.8 到 1.83.10 受影响，修 1.83.11。来不及就在反向代理封掉这个 POST。  
  
CVE-2024-10441  
9.8 已修

按连字符后的构建号判断：DSM 7.2 升 7.2-64570-4，7.2.1 升 7.2.1-69057-6，7.2.2 升 7.2.2-72806-1，BeeStation OS 升 1.1-65374。

## 04  值得关注  
  
Budibase CVE-2026-122247，8.2 分。单租户自托管实例上，POST /api/global/users/init 的是否已初始化检查用请求体里可控的 tenantId 构造查询，守卫永远看到空库，已初始化的实例也能建全局管理员。隔离没做好之前，先把这个接口在网关封掉。  
  
AIT-GUI CVE-2026-77309，8.8 分。先 GET / 拿一个 session cookie，再 POST /script/run 传绝对路径，就能越过脚本目录限制执行任意 Python，2.5.1 修复。  
  
NGINX HTTP/2 两个洞（已单独拆过）。CVE-2026-123007 是流控窗口溢出，1.9.5 起全中；CVE-2026-123633 是连接槽位不足时的 use-after-free。1.30.7 与 1.31.9 修复，宿主机托管的话等云厂商通知。  
  
Siemens Mendix Studio Pro 的 MCP Server。有网络访问就能远程交互，或诱导用户浏览器发出未授权请求，导致数据访问与工具执行。做 AI 编排落地的团队值得跟进。
