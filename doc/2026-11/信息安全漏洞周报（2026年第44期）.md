1. Google Chrome 输入验证错误漏洞（CNNVD-2026-62571624）  
  
Google Chrome是美国Google公司的一个跨平台Web浏览器。  
  
Google Chrome 157.0.8103.38之前版本存在输入验证错误漏洞，该漏洞源于对用户的输入验证不当，攻击者利用该漏洞可以执行任意代码。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://chromereleases.googleblog.com/2026/11/stable-channel-update-for-desktop.html  
  
2. Apache OFBiz 代码注入漏洞（CNNVD-2026-70458245）   
  
Apache OFBiz是美国Apache基金会开源的一个企业资源规划与电子商务平台。  
  
Apache OFBiz 24.09.x版本至24.09.08之前版本存在代码注入漏洞，该漏洞源于对表达式语言语句里的特殊元素中和不当，攻击者利用该漏洞可以执行任意操作系统命令。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://lists.apache.org/thread.html/7b2syzksp7klt9fvhdg0olldvs2g83lz  
  
3. IBM API Connect 跨站脚本漏洞（CNNVD-2026-72429265）  
  
IBM API Connect是美国IBM公司的一款管理API的集成平台。  
  
IBM API Connect 10.0.8.0至10.0.8.12版本和12.1.0.0至12.1.1.2版本存在跨站脚本漏洞，该漏洞源于网页更新时未正确中和用户的输入，攻击者利用该漏洞可以在受害者浏览器中执行任意JavaScript脚本。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://www.ibm.com/support/pages/node/7295635

1. FlowiseAI Flowise 权限许可和访问控制问题漏洞（CNNVD-2026-51831419）  
  
FlowiseAI Flowise是FlowiseAI公司开源的一款可视化编排语言模型应用流程的工具。  
  
FlowiseAI Flowise 3.1.4及之前版本存在权限许可和访问控制问题漏洞，该漏洞源于存在沙箱逃逸问题，攻击者利用该漏洞可以执行任意操作系统命令。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://github.com/flowiseai/flowise  
  
2. DeepSeek Harness 授权问题漏洞（CNNVD-2026-88391556）  
  
DeepSeek Harness是中国DeepSeek公司开源的一款智能体（Agent）运行时框架。  
  
DeepSeek Harness 0.1.2-alpha.2之前版本存在授权问题漏洞，该漏洞源于缺少对用户的身份验证，攻击者利用该漏洞可以执行任意命令、拦截实时会话流量和日志。     
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://github.com/deepseek-ai/deepseek-harness/commit/3e24087bfaeabe40b58ba2f7b936895b8f93fe27  
  
3. MLflow 服务端请求伪造漏洞（CNNVD-2026-26204818）  
  
MLflow是MLflow组织开源的一个简化机器学习开发的平台,包括跟踪实验、将代码打包成可重复的运行以及共享和部署模型。  
  
MLflow 3.8.0版本存在服务端请求伪造漏洞，该漏洞源于get-artifacts函数在访问资源前未对URI进行正确验证，攻击者利用该漏洞可以获取敏感信息。  
  
目前厂商已发布升级补丁以修复漏洞，参考链接：  
  
https://mlflow.org/
